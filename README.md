# 回响 · 可塑性记忆

**一个会淡忘、会好奇、会主动找你，也会因为你没回而慢慢降温的陪伴系统。**

回响不是“聊天记录 + 向量库”。它把经历、兴趣、自我认识、情绪、驱力和性格放进同一条闭环：看见什么、记住什么、在意什么、什么时候开口，都由可追溯的状态决定，而不是每轮重新猜。

## 0.11.0 是什么

这是「回响」的第一版：控制台从“记忆管理页”变成“她的状态面板”，桥接从“被动应答”变成“有驱力的主动者”。

- **拾光**：兴趣、自我记忆、关联、挂念、最近一轮，每条都带出处；
- **闭环联动**：探索 → 兴趣 → 上下文注入 → 主动提议 → 反馈回写；
- **主动决策**：探索、联系、回看、一起看，按驱力与冷却择一；
- **真实主动**：会发消息，也会因为你没回而轻微降温，回复后回升；
- **慢性格**：探索倾向要跨两个月、两次达标才允许动 1 点主动性，可回滚；
- **可解释**：每轮注入了什么、命中了什么、为什么没注入，都写进 trace。

同一套机制也用于群聊和别的私聊，但私人经历、挂念和亲密关系按对象隔离。

当前桥接产品名为 **心迹桥接**，启动入口、运行引擎身份和管理界面均使用心迹。可塑性记忆提供记忆服务与控制台，和心迹协同管理经历、心绪与成长。

## 为什么值得用

### 1. 记忆会淡，不是无限堆积

普通记忆有保留曲线：3 天、7 天、30 天三档基础稳定度，按重要性和间隔加固，低于阈值才进入可归档。核心与待办不参与普通衰减。

它不是“存得越多越像人”，而是**不常被想起的会沉下去，被反复证实的才留得住**。

### 2. 兴趣有证据，不是模型随口说“我喜欢”

每个兴趣都从至少两条独立来源长出来；一条只能算暂定。探索会连看两轮再换话题，不重复同一个视频，也不反复扎进同一个话题。

### 3. 主动有理由，不是定时打扰

每次主动都要过：安静时段、冷却、理由（挂念 / 新证据 / 久未说话 / 一起看）。发出去之后记录回执；没回按 1 / 4 / 12 / 24 小时轻微降温，回复后回升。

### 4. 性格慢，兴趣快

兴趣可以一周变三次，性格不行。开放性/探索倾向这条慢通道要：≥5 个话题、每个 ≥2 条独立来源、跨度 ≥28 天；连续两次达标才 +1 点主动性，累计最多 +3，可回滚。

### 5. 能解释每一轮

`broadcast-trace.jsonl` 记录本轮用了哪些记忆、哪些兴趣、哪些关联、哪些被边界挡掉。不是“感觉她记住了”，而是能指出是哪一条。

### 6. 默认克制

- 主动联系默认 2 小时间隔；
- 一起看一周最多一次；
- 修复（认错/更正）默认关闭；
- 安静时段 01:00–09:00 不主动；
- 付费功能有独立开关和费用上限。

## 主要功能

## 一条闭环

```
你说话 / 她去探索
      ↓
回廊：经历、摘要、原文
      ↓
拾光：兴趣、自我记忆、关联、证据
      ↓
余音：挂念、未完成的事
      ↓
轮廓 / 潮汐：性格、情绪
      ↓
驱力：自主、胜任、联结、好奇
      ↓
决策：探索 / 联系 / 回看 / 反思 / 一起看
      ↓
执行 + 回执
      ↓
反馈：兴趣沉淀、没回降温、慢通道
```

对应到界面：

| 模块 | 看什么 |
|---|---|
| 总览 | 记忆总量、候选、正在淡出、启动检查 |
| 拾光 | 兴趣、自我记忆、关联、挂念、最近一轮 |
| 回廊 | 时间线、图谱、短期、日记、整理、上下文 |
| 余音 | 正在挂念什么、认识与关系观察 |
| 轮廓 | 六维性格、自我参考、慢通道提案 |
| 潮汐 | 情绪事件、心境、恢复 |
| 年轮 | 成长课堂与练习 |
| 梗库 | 可选梗与用法 |
| 账本 | token、费用、审计 |

| 功能 | 作用 | 默认 |
|---|---|---|
| 长期记忆 | 原话、摘要、候选、归档、恢复、导出 | 开 |
| 保留曲线 | 按内容与间隔决定“还浮着还是沉下去” | 开 |
| 拾光证据页 | 兴趣/自我记忆/关联逐条显示来源 | 开 |
| 探索 | 自己找视频、读字幕、提炼有出处的印象 | 开（预算制） |
| 联动注入 | 兴趣与强关联按规则进入上下文 | 开（owner） |
| 主动联系 | 有理由才发，记回执，没回降温 | 开 |
| 一起看 | 一周一次的共同经历，完成后进回忆 | 开 |
| 情绪上下文 | 当前心情只影响语气 | 开 |
| 叙事 | 近期主线，逐句有出处 | 开（手动/低频） |
| 慢通道 | 探索倾向 → 主动性，可回滚 | 开 |
| 修复 | 被纠正时先认错再改口 | **关** |
| 回看 / 反思 | 只记意图，暂不执行 | 关 |

## 参数与依据（节选）

完整表见 [设计依据](docs/design-rationale.md)。**所有数字都是工程默认值，不是人类认知的测量结果。**

| 参数 | 取值 | 依据 | 边界 |
|---|---|---|---|
| 保留曲线 | `R = 1 / (1 + t/S)` | 幂律/双曲遗忘（Ebbinghaus 1885；Wixted & Ebbesen 1991；Anderson & Schooler 1991） | 未拟合真人自传体记忆 |
| 基础稳定度 | 3 / 7 / 30 天 | 经历 / 普通 / 偏好习惯 | 工程分类，不是人类统一天数 |
| 加固 | `1.15 + 0.35 × min(1, gap/S)`，上限 1.5 | 间隔效应（Cepeda et al. 2006；Pavlik & Anderson 2005） | 只在有不同来源时生效 |
| 可归档阈值 | `R < 0.12` 且 >14 天且重要性 <0.8 | 保留策略，非心理学定律 | 14 天迁移保护 |
| 驱力 | 自主 / 胜任 / 联结 / 好奇 | 自我决定理论（Deci & Ryan 2000）；好奇的信息缺口（Loewenstein 1994） | 权重是工程参数 |
| 主动门槛 | 分数 ≥0.45，冷却 30–240 分钟 | 节律与打扰控制 | 不是“人类联系频率” |
| 没回降温 | 1h −0.02 / 4h −0.04 / 12h −0.05 / 24h −0.05 | 排斥与归属研究（Williams 2007） | 轻微、可恢复、有下限 |
| 慢通道 | 5 话题 / 28 天 / 连续 2 次 / +1 | 人格稳定性与干预效应（Roberts & DelVecchio 2000；Roberts et al. 2017；Larson et al. 2002） | 上限 +3，可回滚 |
| 叙事 | 每句必须逐字有出处 | 叙事身份（McAdams & McLean 2013） | 不是事实核验 |
| 关联 | 同来源 1.0 / 同事件 0.9 / 同话题 7 天内 0.35–0.50 | 扩散激活（Collins & Loftus 1975） | 规则匹配，不是模型打分 |
| 联动门 | bigram Jaccard ≥0.25 或短话题包含 | 词面重合作为保守门 | 阈值是工程选择 |

## 安装

**这不是包含 DSH、QQ、SnowLuma 和全部依赖的一键包。** 需要已有 DSH 环境、Node.js 24+、Python 3.10+，以及可用的 QQ/SnowLuma 链路。

```powershell
# 1. 安装插件（用当前 DSH 的本地插件入口）
# 2. 检查环境并准备记忆服务
npm run doctor
python -m pip install -r memvec/requirements.txt
npm run start:memvec

# 3. 安装/更新桥接运行时
node bridge/install-all.mjs --target "D:\your-dsh\qq-bridge" --check
node bridge/install-all.mjs --target "D:\your-dsh\qq-bridge" --apply
```

打开 `http://127.0.0.1:3080/dsh-feiyu-memory/`，在总览确认记忆库、桥接、QQ 三项状态。

详细步骤、升级与回退见 [用户手册](manual/USER_GUIDE-0.11.0.md) 和 [升级指南](UPGRADE.md)。

## 数据与隐私

- 默认数据根目录 `~/.dsh`；记忆库在 `memvec/memories.db`；
- 桥接状态在 `qq-bridge/state/`：`continuity.json`、`taste.json`、`self-memory.json`、`repairs.json`、`shared-activities.json`、`broadcast-trace.jsonl` 等；
- “本地保存”不等于全部离线：提取、摘要、探索提炼、叙事会调用所配置的模型；
- 不公开真实聊天、人格、数据库、令牌或白名单；发布包不含用户数据；
- 私密日记加密存储，但本机管理员仍可能读取，不是端到端加密。

---

## 已知限制

- 记忆提取、兴趣提炼、语义判断都会出错；独立检查不是准确率保证；
- 主动消息可能打扰；默认参数是折中，不是每个人都合适；
- 关键词式的“修复”识别会误判，所以默认关闭；
- 慢通道只动“主动性”一个维度，且需要约两个月；
- 情绪只有一行状态，不等于完整情感；
- 群聊与私聊共享性格倾向，但经历与亲密关系按对象隔离。
