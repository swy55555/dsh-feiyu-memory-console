# 回响 / 心迹

**从聊天驱动，走向有边界的自我驱动。**

收到消息、检索记忆、生成回答，是一个起点。回响与心迹尝试再向前走一步：让对话留下可追溯的经历，让尚未结束的事延续为关切，让下一次回应有上下文；在你允许的范围内，也能在没有新消息时联想、探索、整理，并在条件满足时主动联系。

这里的“自我驱动”指**由已有状态和调度条件发起任务**：有候选、有开关、有预算、有暂停、有来源检查。它不意味着人的意识，也不意味着全天持续思考或所有后台能力默认开启。

## 证据检索开发候选

本工作分支在已修复版本上补入原话混合检索、有界补查和来源修正传播。开发与离线验收完成后仍需单独批准生产切换；没有发布新的回答正确率。机制与边界见 [统一证据说明](docs/evidence-memory.md)，迁移和回退见 [工程步骤](docs/evidence-deployment.md)。

## 不只是把聊天记录存下来

| 从…… | 走向…… | 仍然保留的边界 |
| --- | --- | --- |
| 这轮问了才检索 | 有关切与有限的空闲联想，准备未来可能相关的参考 | 联想有来源、时效和开关，不自动成为事实 |
| 固定角色描述 | 带证据的自我参照与缓慢变化的倾向 | 不训练基础模型权重；可查看、编辑与撤回 |
| 单次情绪标签 | 事件理解、短期状态、恢复与调节 | 工程参数不是心理测量，语义可能误判 |
| 结束对话就结束任务 | 可选的探索、课堂、叙事与主动行为 | 候选计算、实际执行、对外发送分别受控 |
| 看不到回答从何而来 | 来源、记忆、参考投递与用量的可检查记录 | 可追溯不等于模型结论一定正确 |

## 五个视角，一套相互关联的状态

![五个工作区如何联动](docs/images/five-way-linkage.png)

- **拾光**：看来源脉络、兴趣证据与自我记忆，追问“这条印象从哪里来”。
- **轮廓**：看自我参照与六维倾向，理解哪些经历被采纳、哪些变化可以修正。
- **潮汐**：看此刻的情绪、调节与恢复，把短期波动和长期变化分开。
- **余音**：看未结束的挂念、待验证认识与临时联想，让对话之间保留连续性。
- **回廊**：管理长期记忆、短期状态、日记、整理队列、图谱与上下文。

年轮提供成长课堂；账本记录模型用量和费用估算；总览与梗库提供运行概况和表达素材。页面是同一套服务的不同观察入口，不是五个互相训练的独立智能体。

## 关于默认行为、费用与隐私

代码回退值中，定时探索和叙事关闭，课堂需开启；主动决策默认只计算候选，默认不允许主动联系。已有安装会保留原配置，安装预设也可能不同，不能只看默认值判断你的当前行为。

插件本身以 MIT 提供；模型、平台与运行资源使用你自己的服务。后台功能执行时可能在没有新消息的情况下产生模型调用。账本和内部预算是估算，不能替代服务商账单或消费限制。

记忆主要保存在本地，但模型任务可能把相关消息和参考发送给配置的服务商；探索也会联网。不要将“本地存储”理解为“所有处理离线”。来源核对、会话隔离和鉴权能减少风险，不能消除所有模型错误或软件缺陷。
