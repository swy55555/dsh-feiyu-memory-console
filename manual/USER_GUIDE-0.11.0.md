# 回响 0.11.0 用户手册

适用版本：0.11.0
最后更新：2026-11-02

---

## 1. 这是什么

回响是运行在 DSH 上的 QQ 陪伴插件。它做三件事：

1. **记住**：保存聊天经历、摘要和长期记忆，能查到原话；
2. **长出兴趣**：自己去 B 站找视频、读字幕、记录有出处的印象；
3. **主动**：有理由时找你聊天、提议一起看视频，并记录你有没有回。

它不包含 DSH、QQ、SnowLuma 或模型服务，需要你已经有这些环境。

**没有底层人设卡**：开头只有可调倾向，之后由聊天、情绪和兴趣持续塑形。

命名：**回响** 是控制台与插件；**心迹桥接** 是 QQ 运行时；**memvec** 是本地记忆服务。

## 2. 安装前准备

| 组件 | 要求 |
|---|---|
| Windows | 主要验证平台 |

| QQ / SnowLuma | 能正常收发消息 |

## 3. 安装

完整安装步骤（端口、配置字段、自检、排错）见 [安装与部署](../INSTALL.md)。下面只列最短路径。

### 3.1 安装插件

用 DSH 的本地插件安装入口安装 `dsh-feiyu-memory-console-0.11.0.zip`，或把源码目录放到 DSH 的插件目录。

### 3.2 准备记忆服务

```powershell
cd <插件目录>
npm run doctor
python -m pip install -r memvec/requirements.txt
npm run start:memvec
```

首次启动会下载向量模型，时间取决于网络。已有数据库不要新建空库。

### 3.3 安装/更新桥接

```powershell
node bridge/install-all.mjs --target "D:\your-dsh\qq-bridge" --check
node bridge/install-all.mjs --target "D:\your-dsh\qq-bridge" --apply
```

`--check` 只检查，`--apply` 才写入。自定义运行时会拒绝覆盖。

### 3.4 启动

依次启动：记忆服务 → DSH → 桥接 → QQ/SnowLuma。

打开：

```
http://127.0.0.1:3080/dsh-feiyu-memory/
```

## 4. 第一次打开

总览页顶部有“启动检查”，三项都为绿即可：

- 记忆库：能读到数据库；
- 桥接：3100 端口在线；
- QQ：SnowLuma 已连接。

如果桥接不在线，先看桥接日志，不要反复重装插件。

## 5. 九个页面

### 总览

看总量：还活着多少条、多少候选、多少正在淡出。数字是快照，点开可看明细。

### 拾光

最重要的一页。分五块：

- **兴趣**：每个话题的强度、来源、证据条数；
- **自我记忆**：她从视频里记下的、带原文出处的话；
- **关联**：记忆之间同来源/同事件/同话题的联系；
- **挂念**：还没放下的事；
- **最近一轮**：上一次探索看了什么、提炼了什么。

每条都能点开看来源。没有出处的条目不应该存在。

### 回廊

记忆库主界面：

- 时间线：按时间翻；
- 图谱：关联可视化；
- 短期：临时便签；
- 日记：公开/私密；
- 整理：队列与批处理；
- 上下文：回复时实际用了哪些记忆。

### 余音

看“正在挂念什么”、认识与关系观察。可以暂停、结束、否定。

### 轮廓

六维性格：温度、主动、黏人、情绪稳定、玩心、嘴硬。

下方可以看到“慢通道”提案：哪几个话题、跨度多少天、是否已应用。

### 潮汐

情绪事件与心境。这里只影响语气，不改事实。

### 年轮

成长课堂：课程、练习、参考。默认关闭。

### 梗库

可选的梗与用法。需要自己准备素材。

### 账本

token、费用、审计。按功能分项，能看到每次调用。

## 6. 探索是怎么跑的

1. 决策层判断“现在适不适合探索”；
2. 选一个话题：优先当前聚焦话题，没有就从兴趣边缘或种子池里挑；
3. 搜索、挑视频、读字幕；
4. 一次提炼，最多 2 条，每条必须有逐字引文；
5. 写入兴趣（暂定）和自我记忆；
6. 同一话题连看 2 轮再换，跳过最近看过的话题和视频。

### 预算

- 默认每天 0.5 元上限；
- 30 分钟冷却；
- 安静时段 01:00–09:00 不跑；
- 费用以账本为准。

### 你能做的

- 在拾光里删掉不想要的话题；
- 关掉探索（配置 `socialV2.explore.enabled=false`）；
- 调低每日预算。

## 7. 主动联系

### 什么时候会找你

满足全部条件才发：

- 不在安静时段；
- 距上次主动 ≥2 小时；
- 有理由：有挂念 / 刚看到相关新东西 / 你很久没说话。

### 发什么

一句短消息，用挂念的标题，不提熬夜、不催睡、不解释“我在做什么”。

### 没回会怎样

- 1 小时：心情 −0.02；
- 4 小时：−0.04；
- 12 小时：−0.05；
- 24 小时：−0.05；
- 你回了：+0.03，联结 +0.02。

只降不崩，有下限；系统不会发质问或施压消息。

### 怎么关

配置 `socialV2.initiative.contactSend=false`，或把 `allowContact` 设为 false。

## 8. 一起看

她可能发：

> 要不要一起看这个？《…》链接

- 你回“好 / 行 / 可以” → 记为已接受；
- 你回“看完了 / 看过了” → 记为完成；
- 完成后会进上下文：“上次你们一起看过《…》”。

频率：一周最多一次；有进行中的活动不会重复提议。

---

## 9. 慢通道：探索影响性格

### 规则

- ≥5 个话题；
- 每个话题 ≥2 条独立来源；
- 跨度 ≥28 天；
- 两次达标间隔 ≥28 天；
- 每次只加 1 点“主动”，最多 +3。

### 查看与回滚

- 轮廓页看提案；
- `GET /api/persona/openness` 看状态；
- `POST /api/persona/openness/rollback` 回滚最近一次。

### 为什么这么慢

人格稳定性研究显示成年后排序稳定性约 0.6–0.7，干预效应量也不大；所以按“月”而不是“天”。

## 10. 关键配置

| 配置 | 默认 | 说明 |
|---|---|---|
| `socialV2.explore.enabled` | true | 探索总开关 |
| `socialV2.explore.maxCostPerDay` | 0.5 | 每日探索费用上限（元） |
| `socialV2.explore.focusRuns` | 2 | 同一话题连看几轮 |
| `socialV2.initiative.allowContact` | true | 是否允许决定“联系” |
| `socialV2.initiative.contactSend` | true | 是否真的发出去 |
| `socialV2.initiative.contactNoDailyCap` | true | 不限条数，只受冷却约束 |
| `socialV2.initiative.cooldownMinutes` | contact 120 | 联系冷却（分钟） |
| `socialV2.repair.enabled` | false | 被纠正时的认错提示 |
| `socialV2.narrative.enabled` | true | 叙事注入 |
| `socialV2.opennessDrift` | 默认参数 | 慢通道阈值 |

改完配置需要重启桥接。

## 11. 数据与隐私

- 记忆库：`~/.dsh/memvec/memories.db`；
- 桥接状态：`~/.dsh/qq-bridge/state/`；
  - `taste.json`：兴趣
  - `self-memory.json`：自我记忆
  - `continuity.json`：挂念与认识
  - `shared-activities.json`：一起看
  - `repairs.json`：修复记录（默认不写）
  - `broadcast-trace.jsonl`：每轮注入轨迹
- 性格与情绪：`~/.dsh/feiyu-memory-console/`。

备份要连状态目录一起备份；只在运行时复制 `.db` 可能不一致。

## 12. 常见问题

**Q：探索一直不跑？**
看是否安静时段、预算是否用完、桥接日志里的 `explore` 记录。

**Q：主动消息太频繁？**
把 `cooldownMinutes.contact` 调到 240–360。

**Q：兴趣质量差？**
先看拾光里的引文；没有逐字出处的条目应该删掉。也可以关掉探索。

**Q：性格变了想回滚？**
轮廓页看提案，用回滚接口撤销最近一次。

**Q：桥接离线？**
先跑：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "$env:USERPROFILE\.dsh\xinji-launcher.ps1" -Action Check
```

再用“启动心迹”快捷方式。

**Q：升级后聊天记录不见了？**
检查 `~/.dsh/sessions/` 下的项目键是否因路径变化而改变；把旧键目录复制到新键即可。

## 13. 升级与卸载

升级：

1. 备份 `~/.dsh`（至少 memvec、qq-bridge/state、feiyu-memory-console）；
2. 安装新插件包；
3. 运行 `bridge/install-all.mjs --check` 再 `--apply`；
4. 重启桥接与 DSH。

卸载：

- 停桥接、记忆服务；
- 移除插件；
- 数据目录可保留，确认不需要后再删。

---

## 14. 限制

- 会记错、会提炼错；
- 主动消息可能打扰；
- 修复识别会误判，默认关闭；
- 慢通道只动一个维度；
- 情绪只有一行状态，不等于完整情感；
- 群聊与私聊共享性格，但经历按对象隔离。

把它当成一个有来源、可检查、可关闭的陪伴系统，而不是“已经像人”的黑箱。
