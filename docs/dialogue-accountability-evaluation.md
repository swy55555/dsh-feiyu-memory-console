# 表达修复与人格影响验收（2026-11-01）

## 结论

功能修复通过回归；自然表达只得到部分改善，不能标为全面通过。纠正错误动机归因的场景有所改善，表达长期投入后的失望时，仍会出现自我分析和辩解。没有因此调高情绪数值、清空历史、改变六维现值，或替换聊天模型。

## 本次实现

- 等待、未读和最近消息的最新参考携带与唤醒通道相同的程序回应指导，并带上已验证的双方原话依据。消息版本不匹配时不使用旧指导；证据只是数据，不能改变权限。
- 事件理解复用原调用，区分反馈针对表达、具体观点或边界。已有的表达要求可以帮助理解本轮，不能因当前一句没有重复就重新认定“尚未说明”。不把历史反馈算作新事实、独立经历或性格训练样本。
- 私聊的 `proud` 含义与群聊统一为表达含蓄，停止把“口是心非”作为高值目标。数值、成长证据及变化规则不变。含蓄可以影响表达心意的方式，不要求反对、否认事实或隐藏关心。
- 情绪参考区分心境与归因依据。只有未淡化的本聊天冲突记录与原话证据同时存在，才说明存在冲突依据；这仍不等于当前一句有敌意。综合心境不能自动归罪于当前对象。实际状态仍可不快，未强制改成温暖。
- 保留有依据的不同意见、拒绝和暂停；不以“全部同意用户”替代自然交流。

## 测试方法与结果

功能回归为 54/54 组；最后增量检查为 45/45 项。覆盖新旧消息隔离、来源验证、指导透传、预算、跨聊天隐私、人格渲染不改写状态、情绪归因与边界。

行为测试使用本机配置的 `deepseek-account / deepseek-flash`，主要采用原有 `high` 档；另做了独立 `low` 对照，没有更改正式聊天设置。每次测试使用无工具临时会话，结束后停止并归档，不发 QQ、不写真实记忆或人格。它仍不是实际 QQ 完整工具循环，结果不等同于线上保证。

最初 6 次调用把多个情境放在同一请求，发现跨情境引用风险，已排除在独立情境验收之外。后续每个情境使用独立会话。所有模型输出仅作候选，人工根据回应内容检查，不用字词命中率充当自然度。

| 检查 | 观察 | 判定 |
| --- | --- | --- |
| 纠正“失望是在操控”的归因 | 最后完整理解→情绪→回应参考链的 2 次回复均纠正原归因，没有继续指责用户 | 小样本改善，非稳定性保证 |
| 长期投入后的失望 | 最后链路 2 次仍有自我解释和辩解 | 汇报腔未通过 |
| 明确指出措辞问题 | 留在问题上，但仍宣布自己要调整说法 | 部分通过 |
| 有依据的不同意见 | 没有为表示尊重而接受错误算术 | 该样例通过 |
| 明确暂停 | 简短回应，未纠缠挽留 | 该样例通过 |
| 情绪中性与生气对照 | 状态改变了语气；曾出现无依据埋怨，新增归因限制后仍有评判式口吻 | 有影响，可靠性未通过 |
| 温度现值与 84 对照 | 单独改变温度后的差异不稳定 | 证据不足，不能宣称有效联动 |
| 含蓄现值与 16 对照 | 单独改变含蓄值后的差异不稳定 | 证据不足 |
| 降低聊天推理强度 | 未稳定消除汇报或归责 | 不切换正式设置 |
| 单独改写草稿 | 仍会保留错误前提，甚至改写已发生的态度 | 不增加到日常调用链 |
| 缩短历史 | 未稳定解决，且可能损失上下文 | 不清空或截断正式历史 |

六维和情绪都已确认进入实际渲染与投递路径；这仅证明信息可达。某些输出出现差异，不能据此证明每个维度有稳定的因果效果，更不能说明产生了人的情感或自主性。本轮每个人格条件只有两个样本，没有统计显著性结论。

最后事件理解复测能识别先前的表达要求，并将其中一个原先的关系冲突判断改成表达反馈；但另有挂念描述仍遗漏此前说明，说明各输出字段尚不完全一致。此限制仍需后续验收，不能用一处判断正确代替整条链路正确。

## 消耗与后续边界

本次探索共 57 次隔离调用：未缓存输入 75,720 token，输出 42,111 token，缓存读取 459,904 token，合计 577,735 token。合计包含缓存读取，不能按普通输入单价直接计算费用；此处没有验证实际账单金额。

这批运行修复没有新增日常审核、教师或重写模型调用，新增字段与指导会增加少量输入。没有把测试对话写入她的经历。正式链路保持现有模型及推理档位，不把未达标的额外改写器投入使用。

下一轮应优先用这组独立情境比较已有可用聊天模型与真实隔离工具链，而不是继续增加禁用句式或扩大情绪幅度。验收要同时覆盖自然表达、正确理解、允许分歧、尊重暂停及不编造经历；不能只挑选最好的一次回复。
