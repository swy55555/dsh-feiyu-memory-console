# 心迹：QQ 能力迁移与保留边界

正式版本：0.10.0。

心迹以经历、可塑记忆和当前心绪组织陪伴体验。本次建立独立启动入口与可复用的访问策略，继续通过 QQ 兼容适配层使用现有收发链路。它没有重新实现 QQ 协议，也没有声称全部桥接逻辑已完成拆分。

## 当前实现

- `bridge/xinji-engine.mjs`：部署后为 `src/bridge.js`，现有守护脚本无需换启动命令。只启动一个兼容适配程序；`--describe` 查看引擎身份，`--check` 只检查直接依赖的本地模块，不连接 QQ/DSH、不读写聊天状态。
- `bridge/xinji-policy.mjs`：实际入站、唤醒和 HTTP 路由共用的白名单、黑名单、模式访问和会话 key 规范化。保留数字/字符串 QQ 号兼容与原有访问规则。
- `bridge/bridge-v09.js`：QQ 兼容适配层，仍承载二代调度、媒体工具、认证、模型调用及管理接口。现阶段保留文件名，避免把重命名误写成完成整套重构。
- `bridge/xinji-identity.mjs`：状态接口的公开心迹身份，不含账号、配置或聊天数据。
- `bridge/retire-lexicon.mjs`：迁移已知版本 QQ MCP，移除自动黑话工具；未知自定义实现拒绝修改。原文件进入统一安装备份，安装后改动受保护，回退恢复原字节。

## 保留与删除

| 能力 | 处理 |
| --- | --- |
| QQ 收发、SnowLuma 与 DSH 会话 | 保留现有适配，继续处理连接、事件、发送与错误 |
| 白名单、黑名单、主人身份、模式、会话令牌 | 保留并复用，不因心情改变权限 |
| 二代仿真 | 保留未读水位、最近消息、唤醒条件、暂停、群参与、消息合并、节奏控制与工具开关 |
| 发送、引用、图片、表情包、语音、提醒等工具 | 继续兼容；具体可用性仍取决于原环境及开关 |
| 可塑性记忆的玩梗 | 保留“玩梗”页面、`memes.db`、查询工具 `qq_meme_lookup`、候选注入与使用记录 |
| 自动黑话学习 | 删除群聊采集窗口、提取、研究、后台会话、定时触发、候选管理和黑话表注入 |
| 黑话查询/提交工具 | 移除 `qq_slang_query`、`qq_slang_submit` 与对应桥接接口 |
| 性格、情绪、心绪、长期记忆、近期便签、日记 | 保留现有联动与证据边界 |
| 费用账本 | 保留分项、历史核对和剔除记录；历史标签不是运行中的黑话功能 |

**玩梗与自动黑话学习是不同功能。** `memes.db` 和 `meme-play.json` 不应作为黑话数据删除。旧 `slang.memeInject` 仅作为玩梗开关的兼容读取；新字段 `memeInject` 优先，不读取旧黑话词条，不恢复学习开关。

## 安装与回退

本版本需部署到已有 QQ 桥接目录；源码目录不含所有基础适配文件。独立启动入口不等于一键完整环境。不能将 `--describe` 或 `--check` 成功当成 QQ 在线证明。

统一安装器管理 25 个运行时文件；存在需要迁移的已知 QQ MCP 时，额外将该文件纳入同一备份与回执。先检查全部内容和语法，后统一写入，失败恢复，重复安装不重复改写。

```powershell
node bridge/install-all.mjs --target "D:\your-dsh\qq-bridge" --check
# 停止 DSH、QQ 桥接和独立记忆服务，并备份数据后：
node bridge/install-all.mjs --target "D:\your-dsh\qq-bridge" --apply
```

新 MCP 工具清单需重启 DSH 的对应 MCP 进程才能刷新。升级后检查心迹身份、二代工具可用、玩梗入口存在、QQ 在线，再验收真实聊天。

回退使用同包 `--undo`，恢复桥接入口、原适配和 MCP 文件及旧回执。安装器不删除原始账本、记忆库、旧词库文件或备份；旧黑话数据不再被新运行时读取，若要物理清理，应单独备份并只处理 `slang` 专属文件，不能误删玩梗库、表情库或其他后台任务数据。

## 后续架构边界

身份与权限、可成长倾向、短时心绪继续区分。启用自我参考后，旧角色卡退出当前回应；保留六维倾向并与带证据的自我参考共同参与回应与心绪理解；详见 [可成长的自我参考](self-reference.md)。QQ 会话调度仍沿用兼容适配层；不把自身回复、模拟经历或同一条反复出现的反馈当作独立成长证据。

心绪设计的来源署名继续保留：小凌「心光」设计，以及 QQ 用户夜怀瑾、小甘心的贡献，见 [致谢](../ACKNOWLEDGEMENTS.md)。QQ 适配沿用现有桥接能力，不宣称全部代码从零编写。

后台按模块设置推理档位与超时取消说明见 [后台思考强度](background-reasoning.md)。此项需要同时升级宿主插件与桥接运行时；仅升级桥接时会拒绝后台生成，不会回退到会修改全局默认模型的旧接口。
