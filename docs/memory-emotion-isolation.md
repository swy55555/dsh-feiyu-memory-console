# 记忆共享与全局心情（0.10.1 开发版）

## 普通内容可以共享，私密内容单独保护

原文、摘要和事实仍保留聊天归属，用来辨认谁说过什么。开启“跨聊天记忆共享”后，普通事实和旧 `global` 通过隐私判断即可参与其他聊天的相关检索，不需要逐条授权。不是把全部历史塞进每条消息，也不会把别人的喜好当作管理员的喜好。

私密或暂不确定的内容不自动共享；未确认、删除、到期记录也不共享。判断结合记忆和原话，不使用固定词表匹配。原始聊天不会整段带给其他聊天；普通共享只带被允许的事实。语义判断仍可能出错，不能承诺自动过滤绝不遗漏。

首次相关检索时，每批最多审核四条事实，加最多两条摘要，合计不超过六条。结果绑定记录、原话、归属和有效期等内容版本，保存到本地数据库；换聊天不会为同一版本重复付费审核。相关内容修改才重新判断。失败本次不放行，同一版本至少一小时后才可重试，重启仍保留退避。没有批量扫描全部历史的常驻任务。

“共享隐私判断”单独计费，复用已配置的后台模型，默认 high，可在后台推理强度中调整；每批生成等待上限十二秒，超时取消，保留已有审核结果和同聊天记忆。它会增加首次相关检索的等待和 token；后续缓存命中不新增该审核调用。检索相关性使用本地向量。

## 网页的共享范围

在长期记忆库中打开已确认记录的“共享范围”：

1. 查看普通、私密、不确定、未审核状态，以及是否管理员手动设置。
2. **设为私密**：禁止进入其他聊天，优先于目标授权；内容修改后也继续保护。
3. **设为普通**：管理员核对后允许自动共享，修改内容后需重新判断。
4. **重新交给自动判断**：清除本条隐私判断，下次相关检索再评估；不会清除已设置的目标禁止。
5. 可选指定目标：单独授权/恢复，或禁止带到该聊天。撤销授权同时禁止该目标，普通共享也不能绕过。

总开关关闭会暂停跨聊天检索，不影响同聊天记忆；手动设置不会偷偷打开开关。撤销无法收回已发送的聊天内容及已经进入模型会话的上下文。本机管理员仍可管理本地数据库。

## 管理员可以问她在其他聊天聊了什么

复用连续事件理解，识别管理员本轮明确询问其他聊天经历的请求，不另加意图判断调用。仅主人私聊开放跨聊天摘要；需要开启连续事件理解与记忆共享。服务核对摘要时间和覆盖消息中确有角色自己的发言，旁听的群聊不冒充她的经历。

摘要通过隐私判断后只选一至两句安全的原文片段；完整摘要与原始聊天不跨聊天注入。每轮最多两条最近的可分享摘要，进入原有关注预算，因此不是完整聊天审计工具，也不保证能找到所有旧话题。模型摘要可能有概括误差。角色可以讲述、简述或不谈，不能编造未记录的经历，更不强制向管理员汇报。问意判断失效或关闭时，不自动取其他聊天摘要。

## 同一个心情，不同的人际态度

私聊以及群聊中明确发言对象的情绪事件分别保存。当前心情汇总各对象相对基线的有效贡献，并限制在现有量表范围；各贡献沿原有半衰期自然恢复。其他聊天的不愉快可以影响现在的语气、活跃度和耐心，切换聊天不会立即清零。

对当前对象的冲突、挂念、信任和事件依据仍独立。别人让她不快，不会自动算成管理员惹她生气。匿名心情不携带他人的私密原因；需要讲述经历时仍走上述隐私过滤。控制台当前心绪显示共享心情，下方事件记录和回应态度显示主人私聊；事件曲线仍是该对象的历史，不冒充全局历史曲线。

汇总在本地完成，不新增情绪模型请求。每次从原始分组状态重新计算，不将展示结果再次累加；修正误判后对应贡献随之更新。六维性格保留，教师模块仍独立且默认关闭。

## 本机升级

此次按管理员选择开启跨聊天共享，不重置记忆或人格。旧未审核内容首次相关时才判断，不在安装中批量调用模型。保留原始状态备份和既有对象分组；旧版未经隐私过滤的情绪事件转述队列继续停用。
