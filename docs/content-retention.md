# 按内容与经历变化的记忆保留

适用：0.10.1，2026-10-31。此功能是受记忆研究启发的工程实现，不是人脑仿真，也没有经过人类自传体记忆数据拟合。

## 新规则

主人、其他私聊、群聊使用相同规则。系统根据已有记忆分类标签确定基础时间，不扫描正文关键词猜类型，不新增模型判断；未知旧分类按普通信息处理。旧标签中明确的“偏好”“习惯”也兼容。

| 类型 | 重要性0.5时的初始半衰时间 |
| --- | --- |
| 日常经历 `episode` | 3天 |
| 普通信息、计划或未知分类 | 7天 |
| 偏好、习惯 | 30天 |

初始稳定度 `S = 基础天数 × (0.5 + importance)`，其中重要性0～1。现有提取器的偏好通常重要性0.7，因此常见初值实际为36天。数字均为工程默认，不称为“正常人的记忆天数”。

普通记忆的可用程度 `R = 1 / (1 + t / S)`，t 为距写入/最近有效加固的天数。t=S 时R=50%，t=3S时R=25%。R不是事实正确率，也不是模型想起它的实测概率。重要性没有额外的永久保底分；检索仍综合相关性和重要性，所以明确线索可以找到较旧的有效事实。

核心记忆和未完成待办继续免于普通衰减，这是用户控制规则，不是心理学结论。有效期独立保留：现有普通计划/经历默认7天到期；当前修改不续期、不重新确认、不把过期内容当作现状。短期便签、心绪挂念和待验证认识继续使用各自期限。

## 怎样加固

同一人物的新原话再次支持同一已确认事实时，必须有不同来源消息、更晚的原消息时间，并距离上次有效加固至少1天。加固倍率为 `1.15 + 0.35 × min(1, 间隔天数 / 当前S)`，最多1.5倍，S上限365天。间隔按原消息时间计算，延迟处理不冒充新经历。该函数是有界启发式，不是实验得到的统一增长率。

同一消息重试、短时间刷屏、打开网页、向量检索、模型读取提示词都不加固；旧的无证据 `/reinforce` 接口返回不变。后台合并也不自动增长稳定度。候选、过期事实、他人证据不能给已确认记忆加固。

这一规则针对已确认事实的再次支持；“待验证认识”仍要求新的有效证据，重复同一件事不续期。单次强烈情绪不会直接把事实改成永久核心。

## 迁移和归档

首次升级将旧180/2及其历史加固值按内容重新校准；旧值保存在 `memory_retention_migrations`，安装前另有完整SQLite备份。旧计数曾混杂检索、合并等操作，不能可靠还原有效经历次数，因此不把这些计数当作科学依据继续加固。

迁移不改变正文、来源、状态、人物、原时间戳或有效期，不重新调用模型审核。已有关系回执保持可复用，迁移前仍有效的事务撤销回执同步更新非语义指纹，已经失效的回执不复活。重启不会重复迁移。切换后分数下降反映新算法，不意味着删除了经历。

14天迁移保护期内不执行遗忘归档。之后，普通已确认记忆只有在R低于12%、距上次有效写入/加固超过14天、重要性低于0.8时才进入可归档范围；候选、核心和待办不适用。归档是可选的管理操作，需在网页执行，当前没有新增自动归档定时任务。自然淡化随时间计算，不额外调用模型。归档后数据库仍保留，可经过核对恢复。

已修复旧清理阈值被注释吞掉而导致 `PRUNE_R` 未定义的问题；预览、图示和后端使用一致的曲线，迁移保护期会在预览中显示。

## 研究依据与验证边界

- [Donkin & Nosofsky, 2012](https://journals.sagepub.com/doi/10.1177/0956797611430961)：在所研究的识别记忆任务中，模型强度随间隔呈幂律形式。支持考虑幂律形状，但不能推出本插件的3、7、30天或365天上限。
- [Pavlik & Anderson, 2005](https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog0000_14)：词汇配对实验及模型研究练习间隔对保持的影响。支持区分间隔实践与密集重复；本插件没有复现其认知模型，也不将模型反复读取提示词等同于人类提取练习。

单元测试验证范围平等、半衰时间含义、单调衰减、来源与间隔校验、重复不加固、合并不自增、迁移幂等、回执与撤销保留，以及归档保护。它们不能证明具备人类记忆或实际聊天质量提升。下一步应依据用户纠错、相关事实召回率和不该出现的过时事实比例评估，避免用“忘得像人”掩盖漏记。
