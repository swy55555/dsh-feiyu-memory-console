# 轻微正面事件不再削弱已有同类感受

此前模型输出的本轮感受强度被当作“整体感受的目标值”。已有较强温暖时，新问候带来的温暖较弱，旧公式 `old * 0.2 + target * 0.8` 反而会降低温暖。

修正后，evoke 表示有上限的新刺激，不向下覆盖同类感受；时间淡化仍由原有时间函数处理，明确释怀仍使用 settle，负面感受仍有自身影响。不是把所有事件强制改成加分，也不新增模型调用。

在相同初始状态、相同记录时间、相同已保存模型判断下离线重放：

| 原话 | 修正前舒适度变化 | 修正后舒适度变化 |
| --- | ---: | ---: |
| 你在干嘛呢 | -0.020877 | +0.002896 |
| 哦～嫌我敷衍你啦？ | -0.005283 | +0.009558 |

重放不写回真实经历，也不更改历史触发记录。页面新增组合心境、本轮实际采用的细微感受，并说明 neutral/none 不是没有感受，分类把握不是心情分数。记录中的本轮变化不含事件之前的自然淡化。
