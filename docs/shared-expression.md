# 各聊天的自然表达与共同性格

此改动属于未发布源码。安装状态以本机安装回执为准，不代表 v0.10.1 已发布资产已经包含。

## 改了什么

- 主人私聊、其他私聊和群聊都能读取同一套缓慢变化的六维数值倾向。非主人聊天只读取预定义维度及有效数值，不复制主人私聊的身份经历、证据、历史、自定义标签或私密文本。共同性格不等于共同亲密关系。
- 先回应当前话题的具体内容，减少把自主性表达成反复“接不接、认不认”的立场声明。不同意见和拒绝仍然保留，当前对象的明确偏好优先。
- 群聊要分清说话人和对话目标，不把一人的玩笑、昵称或互动邀请当作对所有人的约定。
- 语音和表情为可选媒介，不以随机建议覆盖文字要求、认真提问或必要说明，不再强制文字最多一句。
- 保留完整自然表达规则。不能靠编造个人线下经历、共同过去或相似遭遇制造亲近感。

## 调用与费用

这些改变通过现有聊天参考组装完成，不增加每条消息的独立事件判断、润色或审核调用。共享数值与新增表达指导会增加少量输入文本，因此不是零 token 增量；实际费用还受缓存和模型输出影响。本次没有给群聊和其他私聊启用原本仅主人私聊使用的独立连续事件理解。

## 验证与限制

结构测试验证了真实投递包装中的三类聊天、私人信息隔离、无效维度拒绝与媒介建议边界。完整回归 46 组通过，整理页面桌面和移动端检查通过。

离线试写使用六个人工情境，包括群聊玩笑、观点不一致、其他私聊分享成果、表达纠错与明确不回复。前后对照都使用更新后的共同文风段，主要比较自我参考的变化，因此不能视为整个旧版与新版的严格对照实验。样本中边界得到遵守，立场式表达有所减少，但首次新版样本编造了“我最近也在调参”的个人经历；补充来源边界后的一次复测未再出现该自述。复测仍有偏套路的追问，不能据此宣称理解能力或人情味已经全面解决。

三次完成的试写合计记录 13,956 token，其中缓存读取 10,752、普通输入 2,313、输出 891；前期因历史接口不兼容而中止的尝试用量未完整核实，不包含在此统计中。试写未向 QQ 发送消息，也没有写入成长或记忆。后续应观察真实聊天中是否回应了具体内容、是否正确识别对话对象和当前偏好，而不是仅统计禁用句式出现次数。

本次没有修改聊天模型权重、重置人格或声称系统具备人类意识。若真实聊天持续出现“理解方向正确但措辞生硬”，下一步需要检查实际预设叠加、上下文负担及聊天模型本身的表达表现，而不是不断增加后台调用。
