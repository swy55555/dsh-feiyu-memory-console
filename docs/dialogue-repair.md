# 对话时序与交流反馈修正

这次修正针对连续纠错中的旧回复、汇报式自我解释，以及把“允许不同意”误用成“必须顶撞”。不承诺模型从此完全自然，也不靠增加情绪数值制造争吵。

## 实际行为

- 同会话的二代私聊文本回复，在每条气泡即将发送时核对输入序号。尚未读到的新消息或排队期间的新补充，会取消旧回复剩余部分；工具返回已发送数量及读取新消息的提示。不撤回已发内容，不清空未读，不自动重发旧句子。群聊和明确跨聊天转达不使用这条私人回复检查，权限校验仍保留。语音/唱歌发送接口没有改动。
- 临时表达要求不再一律互相替代。一次最多取最近三条有效要求合并成一个参考块；明确冲突或撤回才由已有事件理解输出被替代 ID，本地校验聊天与有效状态。未提供替代关系时，当前明确要求优先；模型语义判断仍可能不准。旧版已经标为替代的内容不自动复活。
- 自我参考增加用途：自身参考、交流反馈、对方表达偏好。后两者保留原文与证据，页面可见，不注入当前人格台词，也不凭新反馈推动六维增长。自我参考与反馈各最多 16 条。旧条目不会按关键词批量重分类；安装本机时只应用逐条核对且正文哈希一致的计划，另存备份和历史，六维现值不变。
- 完整自然表达规则保留，补充想象互动和现实能力查证的区别；许可不等于命令，不把失望解释成操控，不凭空编自身紧张或讨好作为原因，未解决的问题不擅自转成催睡。明确暂停与现实身份问题仍分别尊重、如实回答。

## 成本与限制

没有新增每轮润色模型、模型审核器或定时付费任务。表达要求的替代判断复用已有事件理解，输入输出会增加少量字段。发送因新消息取消时，聊天模型可能需要读取补充并重新组织回复，不能承诺每种连续输入场景都减少 token。

离线试写使用无工具后台预设，不发送 QQ，不写真实记忆；测试消耗单独保留报告。短场景试写不能证明长时间争执已修复。此次试写中，亲昵想象、暂停及现实能力边界较稳定；连续追问中的自我说明和整改口吻仍有残留，不将其记作自然度验收通过。

预设安装只替换既有自然表达段落，并保留工具、权限、模型与用户定制配置。修改后须同步预设产物并重启；“文件同步”不等于能直接观察模型最终采用了哪条规则。
