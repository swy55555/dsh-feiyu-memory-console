# 成长课堂

## 使用方法

成长课堂是独立页面，默认关闭。它保存外部课程经验和提示参考，不更新模型权重，不改写六维性格，不把练习写成真实经历。

1. 点“＋ 新建课程”，填写名称、具体目标和适用场景，可附对话和示例。也可从“自然说话”“讲故事”模板开始。保存不调用模型。
2. 最省钱的方法是“自己写参考”。需要模型帮助时，开启课堂并点“生成学习草案（最多1次调用）”。
3. 核对方法、避免事项、模拟示例和检查要点。你可编辑参考，再点“已核对，启用这份参考”。格式通过不代表内容正确，更不代表已经学会。
4. 同时开启“连续事件理解”和“本轮关注筛选”后，相关主人私聊才选择课程。选课复用已有事件理解。当前心绪的“本轮用量与来源”可查看是否选入；选入不等于回复已采用。
5. 根据真实聊天记录“有帮助”或“不合适”；后者立即停用。反馈不自动触发付费重练，不当作能力分数。修改目标会清除当前参考，需重新整理或编写。

可以停用、归档或关闭总开关；不能收回已经发出的消息或已进入模型会话的参考。当前只处理配置中的主人私聊，群聊和其他私聊不读取这些课程。课程独立保存在 `state/growth-classroom.json`。

“说话像真人”可细化成：“日常分享先回应一处具体细节；无求助时不机械给建议；允许不同意见，但不敷衍认真交流”。自然不等于固定短句，也不等于必须嘴硬或必须温柔。当前明确要求、真实事实、边界和有来源的性格优先。技术类课程只是通用方法，不能代替知识核验和执行测试。

## 花费与去重

| 操作 | 新增后台模型调用 |
| --- | --- |
| 创建、编辑、手写参考、核对、停用、反馈 | 0 |
| 明确点击生成，材料或模型配置改变 | 最多1次，失败不自动重试 |
| 相同材料与模型配置已有成功草案 | 0，复用草案 |
| 本轮选课 | 0，复用事件理解 |
| 注入课程参考 | 不另调模型，但增加少量输入 token |

默认 low，可在后台推理设置调整“成长课堂”，聊天档位不变。生成等待最多60秒，沿用后台取消与用量记录；超时不等于远端没有费用。全局单次生成，失败至少一分钟后才可手动重试，重启不自动补跑。

最多保存12门、同时启用3门，每轮最多选1门。目录仅有名称、适用场景和版本；参考最多220字、避免事项最多160字，共享原有2400字符关注预算。模拟例句不放进每轮聊天。没有启用课程时不发送目录。缓存覆盖材料、模型、推理档位和模板版本；编辑或停用使旧的在途结果失效。

费用单列“成长课堂”。调用减少不等于固定比例的费用减少，实际以输入、输出、推理 token 和提供商账单为准。

旧表达教师的多轮自动教学已经停用，旧课程保留只读，旧费用标为“旧表达教师（已停用）”；不会自动当作新课堂的已批准课程。

## 科研依据及其限度

- [Reflexion，NeurIPS 2023](https://arxiv.org/abs/2303.11366)：研究语言反馈与外部文字记忆，而非更新权重。这支持保存经验供后续参考的工程方向，但任务实验不能直接证明陪伴聊天或共情一定改善。
- [Self-Refine，NeurIPS 2023](https://arxiv.org/abs/2303.17651)：在所研究的任务和模型中，迭代反馈改善了表现。本模块为降低花费没有复现其循环，也不借用论文的提升数字宣称本插件有效。
- [Large Language Models Cannot Self-Correct Reasoning Yet，ICLR 2024](https://arxiv.org/abs/2310.01798)：其推理实验发现，缺少外部反馈的自我纠错可能无效甚至退步。这不是所有模型、所有任务永远不能自评的证明，但说明模型自报“通过”不能当作效果证据。

本方案是这些研究启发下、受成本约束的工程选择，不是已经复现并证实有效的科研结论。字数、课程数量和等待时间属于工程上限，不是人类认知定律。

评估时应另留几条没用于教学示例的新场景，以及不相关场景；比较启用与停用的回应，尽量打乱展示顺序。事先约定标准：是否回应具体细节、是否编造经历、是否保留立场、是否机械给建议。不能只看与教师例句像不像。单次好评不证明跨场景能力提升，不同用户应使用各自偏好和反馈。

机制测试只验证调用、缓存、开关、范围和失效处理，不能替代真实聊天质量评估，不宣称获得人的理解能力。

## 关于“确认候选失败”

“历史已复核”只表示完成检查，不代表所有关系都明确。原话通过但仍有不确定关系时，保留待确认并显示数量，不再发送必然失败的确认请求。最后提交仍有事务检查；并发变化被阻止时显示“暂未确认”。确认门槛没有降低，已有事实保持不变。
