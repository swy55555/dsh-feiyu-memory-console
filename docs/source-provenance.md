# 来源版本与证据保留（第 1 阶段基础）

这是未发布开发改动，是否在本机生效以安装回执和服务能力 `source-retention-v1` 为准。

## 已实现

原话现在有来源版本：完整的已存内容、聊天范围、消息编号、说话人、用户/角色作者类型、原始时间和截断标记共同参与计算。否定、标点和条件不被归一化掉。它用于识别具体来源，不表示语义正确率，也不是模型自报置信度。

近期聊天仍保留每聊天 5,000 条，不把全部历史塞进每轮上下文。被记忆或摘要引用的来源会复制到独立证据表，并保存引用关系；近期窗口淘汰后仍可核对。桥接每分钟本地登记挂念、认识、回应倾向、临时表达要求和自我参考的证据，包含已有自我参考历史和认识修订中保留的引用。未变化且已成功登记的内容跳过；来源暂缺时十分钟后本地再查。登记没有模型调用入口，不发送 QQ 消息。

记忆/摘要的来源保留由数据库事务及 SQL 触发器维护，覆盖服务和控制台的直接写入；迟到的原话能补上已有候选的来源。桥接的状态登记是异步的：尚未登记且已经被窗口淘汰的来源仍可能无法补齐，不声称所有历史来源都已保住。

迁移只从仍存在的原话建立引用，不拿记忆正文、摘要或模型推测重新造原话。原话找不到时保留现有记录并报告不可核验，不自动删除、不自动确认，也不额外调用模型全库重审。

相同消息编号再次投递只视为重投；内容或说话人不同会返回 `sourceConflict`，不会静默覆盖原话。跨聊天编号不混用。已退出近期窗口但仍保留证据的重投同样遵循此规则。

## 页面怎么看

在记忆卡片里展开“查看记忆来源”，点击 **核对完整原话（本地）**。页面会区分：

| 状态 | 含义 |
|---|---|
| 来源匹配 | 已存原话、说话人与时间匹配；展示版本标识及是否独立保留 |
| 来源经过截断 | 不能核对完整语境；旧记录正好达到截断上限时也保守处理 |
| 来源不可用 | 近期原话和已保留证据中没有对应来源，不代表记忆一定错误 |
| 来源不一致 | 保存片段或时间与现存来源对不上 |
| 标识不完整 | 旧记录缺少来源编号、说话人或片段 |

点击只做本地数据库核对，不调用模型。来源匹配只说明“当时确实保存过这段话”，不能据此认定其内容属实、现在仍适用或支持某个性格推断。

## 删除、撤销与保留边界

软删除/归档与彻底清除不同。记忆软删除仍保留证据，便于撤销；修改来源后，旧引用保留为历史，不冒充当前依据。真正物理移除记忆/摘要时释放其引用；没有其他引用的独立证据副本随之移除，其他记录仍引用的来源继续保留。

桥接能在完整且未变化的状态快照下释放已从状态文件及其保留历史移除的记录。文件缺失或不可解析时不把它当作“全部清空”。同一来源可能被多个模块引用，删除一条记忆不会连带擦掉其他引用者的依据。

本阶段没有新增全会话隐私擦除接口；已有软删除不应被描述为擦除所有原话、审计和备份。专门删除来源及其派生副本的协调处理，以及自动纠正联动，仍属于后续阶段。没有自动清除旧备份。

## 验证与后续

隔离测试覆盖超过窗口后的核对、跨范围与跨人物隔离、版本稳定、异常重投、迟到原话、完整批次校验、软删除撤销、最后一个物理引用释放、来源缺失、截断标记和迁移幂等。迁移预演使用数据库副本，禁止模型/向量调用。

已建立来源保留基础，尚未实现自动把一次澄清传播到所有认识和性格参考。下一子阶段先做纠正影响预览，再接版本校验、联动失效与必要的定向重评。当前不新增另一套记忆确认队列。

## 纠正影响预览（1D）

在同一张记忆卡片的“查看记忆来源”里点击 **查看纠正影响（只读）**。它以已核对的原话版本为起点，列出同一聊天内登记的记忆、摘要，以及心迹的挂念、认识、回应反馈、表达要求和自我参考；桥接尚未登记但当前状态明确引用同一原话的记录也会纳入。

- 当前引用：记录现在的来源字段或证据列表包含这句原话，不表示一定被检索、采用或正在生效。已撤回、归档等状态另行显示。
- 历史引用：来源已改动，或只保留在修订、自我参考历史中；不会显示成当前依据。
- 暂不能核验：曾经登记过，但当前文件不可用、格式异常、证据不再匹配或记录不在现有快照里。不能视为无影响。

仅按明确来源编号、聊天、作者和摘录匹配，不用语义相似度推测因果。数据库在只读事务中查询；桥接文件随后读取，所以两者不是一个原子快照。继续聊天后需要重新点击刷新。预览附来源版本和快照摘要，为后续提交校验准备，但本阶段没有纠正提交接口。

**范围限制**：当前覆盖明确的直接来源引用，以及下文有版本的“记忆 → 联想 → 当时感受”路径。摘要再影响认识等其他间接派生关系尚未完整登记，性格数值与课程派生链也未纳入；不能把清单当作全部影响。前端最多展示 100 条，超出会提示，统计包含未展示项。没有来源时显示不可核验，不显示成“影响为零”。

查看不会修改记忆、确认候选、回退性格、追加审核或调用模型；不扩大跨聊天共享。纠正后的失效传播和定向重评属于 1E/1F，尚未启用。

## 有版本的间接路径：记忆 → 联想 → 当时感受

新产生的空闲联想会在现有本地审计中保存逐节点来源：聊天范围、记忆编号、记忆内容版本、已核验的原话版本。只有程序实际采用的那一项主观感受才登记为感受节点；其他候选印象不会冒充当时生效的感受。

纠正预览沿原话版本找到这些历史生成路径，展示经过哪条记忆、哪个联想节点。多个记忆作为并列来源显示，不伪装成互相推导。记忆后来发生变化或已经移除，路径会标明父记录的现状；历史生成记录不表示当前仍在生效，也不证明最终回复采用了它。

旧审计没有逐节点版本时，只提示“无法确认具体影响”，不从相似文本倒推关系。审计仍沿用最近 7 天、最多 40 个事件的范围；不回填历史、不无限保留全部联想。原话已不可核验或记录超出审计保留范围时，不能承诺完整追溯。摘要到认识、课程或人格变化等其他路径尚未覆盖。

版本只附带于联想已有的本地 `/related` 和 `/lookup` 请求，其他调用默认不附带；模型提示词剔除这部分元数据。新增记录与预览没有新增模型调用。联想带入聊天前复用原有本地复核，记忆版本改变就放下旧联想；无版本数据仍按原来的正文/时间核验，并在预览中标为缺少版本依据。本次须一起更新桥接与记忆服务；不支持新增请求字段的旧服务不能用于完整验收。

以上是 1D 间接路径阶段的记录，当时没有启用自动纠正提交、跨模块失效传播或情绪/性格数值回退。

## 后续进展：1E 基础

已实现明确的整句来源撤回、当前参考暂停和不覆盖后续修改的撤销。此前各小节所述“没有纠正提交”描述的是 1B–1D 当时的边界。新入口、适用范围、安装验收及未覆盖部分见[来源纠正联动](source-corrections.md)。仍未自动从聊天发起纠正，也不把旧模型上下文视为已清空。
