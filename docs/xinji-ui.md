# 心迹桥接管理页

本次改版覆盖心迹本地管理页（默认端口 3100），采用低饱和青绿与暖杏色，提供浅色、深色主题以及少量光晕动效。

## 从哪里开始

- **运行总览**：查看 DSH、QQ 网关、当前模式、会话与待处理请求。页头显示后端实际版本，不把未知连接显示成在线。
- **启用与成长**：三步检查环境、选择成长功能和全新状态的性格起点，保存前核对；已有用户保留性格与经历。查看 [首次使用说明](first-use.md)。
- **心绪、成长、记忆入口**：分别打开可塑性记忆控制台的当前心绪、六维与自我参考、长期记忆页面。它们仍属于原有功能，改版没有复制另一套状态或模型调用。
- **会话与审批**：查看会话映射、提问和审批。
- **人格与指令**：保留完整底层提示词及编辑、备份恢复入口，自我参考和六维成长入口独立可见。
- **聊天行为**：一代与二代仿真参数完整保留，调整后仍按原规则保存。切换页面不会主动清空未保存的表单草稿。
- **管理**：保留用量、白名单、访问令牌、调试和工具参考。

## 外观操作

首次打开输入访问令牌，点击“连接并记住”。以后在同一浏览器使用同一地址，刷新、切换页面和重开标签页会复用已保存的令牌。令牌更换、清除网站数据、换浏览器或结束无痕会话后需要重新登录。建议固定使用 `http://127.0.0.1:3100/`；`localhost` 和 `127.0.0.1` 是不同的浏览器存储位置。禁用网站存储时只能在当前页面保留令牌。

取消登录后，点击右下角“登录控制台”可重新输入，不会被后台轮询反复弹窗。页面框架可在登录前加载；真实状态、提示词、白名单和保存操作仍需要有效令牌。令牌保存在当前设备的浏览器中，请勿在不信任的设备上登录。

右上角切换深浅主题，选择保存在当前浏览器。总览右上角的“暂停光晕”只控制装饰动画，不改变角色心情、聊天行为或后台任务。系统启用“减少动态效果”时自动停止动画，并优先遵循系统设置。

光晕和细线属于页面装饰，**不是实时情绪数值或意识活动的测量**。实际心绪请进入“当前心绪”查看来源和变化记录。

手机或窄窗口使用左上角按钮展开导航；点击页面、遮罩或按 Escape 关闭。支持键盘操作、焦点指示及屏幕阅读器标签。版本在手机页头也保留。

## 数据与费用

外观、切换主题、开关动画不调用聊天模型，不更改白名单、人格、记忆、提示词或费用数据。已有只读状态轮询继续运行。心绪和记忆入口只是正常页面导航，不启动生成。

本次提供浏览器检查命令：`npm run test:browser:xinji`。测试使用隔离的接口返回，不发送真实 QQ 消息；覆盖九个页面、主题、窄屏、键盘导航、动效设置、空数据、连接失败和表单草稿。
