# 统一证据与检索：开发候选说明

基线：`142e99e99ae55135e20d9596072975c7d11ef94a`，保留之前的来源修正、范围隔离和 DailyMemory 修复。本说明对应 P0—P4 开发候选，尚未切换生产；不是已发布版本的效果承诺。

## 来源契约

复用 `messages`、`evidence_sources`、`evidence_links`、`evidence_source_lookup` 和 `source_corrections`。原文不另建无期限副本，摘要不能回填成原话。`evidence_fts` 和 `evidence_vectors` 是可重建索引，不是独立保留依据。长期保留仍需已有来源链接；窗口淘汰且没有保留链接的原话无法恢复。

| 字段 | 含义与约束 |
| --- | --- |
| `sourceId` / `messageId` | 既有事件或原话 ID；不要把派生记忆 ID 当成一次新的经历 |
| `sourceVersion` / `rootIds` | 原文内容、主体、作用域等生成的来源版本；多次转述共享证据根 |
| `scope` / `speaker` | 精确会话和实际发言者；当前聊天的补查不得换作用域 |
| `sourceType` | participant-utterance、character-utterance、organized-fact、derived-experience、external-document；角色说过不等于用户经历过 |
| `spokenAt` | 记录中的发言时间；数据集模拟的会话内秒数不等于真实测量时间 |
| `eventAt` / `plannedAt` | 无可靠结构化记录时保持 null；计划不视为完成 |
| `recordedAt` | 只有真实记录时间可知时填写；未知原话入库时刻不拿发言时刻冒充 |
| `state` / `moduleVersion` | observed、active 等状态与契约版本；候选不因命中检索而转正 |
| `causalId` / `idempotencyKey` | 关联触发事件与幂等身份；读取、命中、采用均不算新增独立证据 |

外部资料的来源根由网址、作者、摘录生成；作者未知时显式标记。拾光里的印象与资料不变成用户偏好。旧模块继续使用其原有 evidence/eventId/sourceEpisodeIds，通过兼容消费器关联上述版本，避免批量重写历史业务表。没有可核对来源的旧状态不伪造来源契约。

## 模块读写与联动

| 模块 | 当前读写位置 | 消费与产生 | 来源变化及关闭行为 |
| --- | --- | --- | --- |
| 拾光 | `taste.mjs`、`self-memory.mjs`；taste.json、self-memory.json、探索记录 | 外部来源与摘录 → 有出处的兴趣/自我记忆；同根转述不叠加强度 | 失效来源排除当前召回与联动；保留历史。探索开关仍由原有调度器控制 |
| 轮廓 | `self-reference.mjs`、`self-temperament.mjs`、自我参考状态 | 原话事件 → 版本化自我参照；保留跨经历、天数、冷却与幅度门槛 | 来源失效暂停依据；手动 revision 与来源 revision 阻止迟到结果覆盖。不开启额外自动成长 |
| 潮汐 | `emotion.js`、`emotion-scopes.mjs`、事件与情绪状态 | 当前事件与有效依据 → 有界感受与历史事件 | 失效来源不作为当前原因；历史体验不做数值反演；检索与事件重放不再次施加增量 |
| 余音 | `continuity.mjs`、`chat-clarification.mjs`、`idle-association.mjs`、`mind-workspace.mjs` | 当前理解与原话 → 挂念、暂定认识、短期联想及候选 | 失效挂念关闭、认识撤回、临时缓存清空；旧草稿不得发送；原有关闭/暂停/权限门槛保留 |
| 回廊 | `lib/core.js`、确认/整理/候选审核、`memvec/server.py` | 管理操作 → 业务事务、来源修正、检索与审计视图 | SQLite 触发器覆盖 Python 服务和控制台直接 SQLite 写入；不依赖页面发送临时通知 |
| 课堂、日记、叙事、主动行为 | `growth-classroom.mjs`、diary-state.json、`narrative.mjs`、桥接调度 | 用户课程、明确来源的事件及已有状态 → 方法参考/叙事/行为候选 | 来源依赖失效后排除；课堂和叙事生成、主动发送前复核；方法参考不是事实、人设或发送权限 |

处理链：原业务事务 → 同事务写入不含正文的 `evidence_changes` → 桥接每 5 秒按 sequence 消费 → 各模块状态与 `_evidenceCursor` 一起保存 → 最后保存全局 cursor。模块保存失败不确认消费；已保存但未确认时重启，依靠 cursor 重放去重。缓存和在途结果即使被重复失效也不产生状态增量。

来源变化会更新即时只读 `SourceValidity`。因此消费器延迟不意味着旧资料可以继续发送：检索、当前理解、派生结果和主动发送仍有来源版本复核。更新关闭、撤回等当前状态，不删除已经发生的历史感受。模块关闭后不启动其模型任务；无模型的索引一致性维护、来源通知和审计继续执行。

## 检索与上下文

原话可在提取尚未成功时被检索。融合 FTS5 trigram、参数化短词匹配、现有有效记忆向量、原话向量、主体和明确发言时间筛选；根版本去重。向量记录保存模型名与维度。模型不匹配或嵌入失败时退回原话关键词检索并标记 unavailable，不能假装向量成功。后台只使用已有本地嵌入模型逐批索引。

既有 `qq_vmem_search` 使用本轮随机 ref 做相邻原话补查；不可使用别轮或别会话 ref。原话展开只取同作用域有限时间邻域，再经过来源有效性验证。工具不发送消息、不自动确认候选、不强化记忆。

自动召回、后续消息参考和手动工具共享同轮预算：默认 4 次请求、10 条、6000 个字符；一次请求超时 2 秒，最多同时 2 个检索。缓存失效不会清零本轮花费。空结果、无新证据、无效 ref、过期回合、超时和预算耗尽均有明确状态；失败不能描述为“翻遍了所有记录”。工具本身不调用付费生成模型，但检索出的上下文进入聊天模型后仍可能增加输入费用。

统一装配默认 8000 字符，完整记录装入，避免上游放大后又截断为 500 字符。根相同的资料不重复加入，近期原话与命中原话也去重。未实际装入的检索记录释放交付配额，调用次数不返还。当前请求和既有保护参考不强行裁切，因此报告可能标记 `protectedOverflow`；这不是严格的整条模型输入硬上限。对当前表达的纠正/反馈，新的自动原话参考暂缓注入，避免脱离情境的旧许可覆盖当前要求；有情境核验的旧通道仍保持既有规则。

审计分开记录请求、命中、根去重/预算丢弃、最终装配与交付。检索命中不等于模型实际采用。人工历史展示可保留失效条目；进入当前参考的读取路径须过滤 `sourceState: invalid`。

## 时间、恢复与覆盖边界

目前可识别明确年月日、今天/昨天及 today/yesterday，作为 UTC 发言时间排序提示。严格时间筛选要求显式 `basis: spoken`；没有事件/计划时间时拒绝假装支持该筛选。自然语言的跨月、多跳和事件时间推理仍由模型依据原话完成，不能宣称已有完整时间推理器。

DailyMemory 超限会缩小批次，直到可处理或只剩单条；单条仍超限时保留并诚实报错。独立退避旧消息不阻塞新消息；未覆盖原话、持久化失败和不确定审核不会错误出队。所有回退继承原有来源与审核门槛。

`evidence_changes` 只记身份、变更类型和时间，不存正文，但仍是本地敏感元数据。当前保留完整通知历史以支持重放，尚无自动压缩；长期运行要监控数据库增长，不可随意删除未确认事件。索引可重建；删除原话且无保留链接时同步清除索引正文与向量。

## 离线验证与以后如何比较

原有基线答卷保留。新开发样本从前五组 762 题按对话/题型比例冻结 100 题，剩余 778 题不参与调参。先区分旧自动召回结果、完整接入旧能力、同接入同预算新能力；后两者的真实作答与裁判需要单独授权，不能用来源命中率替代答案正确率。

`freeze-evidence-dev.mjs` 只向运行侧输出问题；`offline-evidence-diagnostic.py` 不读取答案或证据标注、不启动 QQ 或候选模型审核；独立 `score-evidence-diagnostic.py` 在检索完成后才比对来源标签。离线诊断只覆盖首轮检索，不伪装成模型自主补查的完整成绩。受控工具调用、迟到响应、保存失败与重启重放由测试夹具验证。
