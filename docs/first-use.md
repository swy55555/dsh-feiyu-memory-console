# 心迹与可塑性记忆：第一次使用

本指南对应开发版 0.10.1。向导用于检查和配置已经部署的服务，不会自动安装 QQ、SnowLuma、DSH、模型或基础桥接依赖。

## 入口

打开心迹管理页 `http://127.0.0.1:3100/`，在“运行总览 → 启用与成长”点击“打开启用向导”。首次输入访问令牌后，同一浏览器、同一地址会记住登录。若页面还没有这个入口，请确认桥接运行包也已更新，而不只是更新可塑性记忆网页。

打开向导、重新检查以及保存选项均不调用聊天模型，不生成模拟聊天，也不向 QQ 发消息。

## 第一步：检查连接

- **DSH**：检查桥接是否已连接宿主。未连接时先启动 DSH。
- **QQ 网关**：查看 SnowLuma 连接和健康状态。网关连接成功不等于真实消息已送达，最后仍需实际私聊验证。
- **记忆服务**：访问当前配置的本机记忆端口。检查可访问性，不证明数据库路径正确、提取正常或模型已加载；请同时在可塑性记忆总览核对数据路径。
- **主要使用者**：检查当前模式是否允许主要使用者私聊。点击“设置主要使用者与白名单”会回到现有管理页，由你明确设置；向导不会替你放开权限。
- **模型**：显示配置的提供方和模型。这里只读配置，不试调用，不保证余额、密钥或模型可用。
- **后台整理预设**：检查 DSH 是否列出 `qq-memory`。缺失时按安装文档补齐预设。

新环境没有过去的聊天也能正常开始。自我参考为空时会从当下交流回应，不应编造来历、共同经历或现实生活。空闲联想没有真实来源时直接停止，不为填满页面而生成内容。

## 第二步：选择成长方式

进入时显示已保存的设置，不自动替你开启收费功能。“采用建议组合”会选择记忆、连续事件理解和自我成长，并关闭向导中的三项试验功能；最终保存前仍可修改。

| 功能 | 作用与依赖 | 模型用量 |
| --- | --- | --- |
| 可塑性记忆 | 从新聊天提取有原话依据的信息 | 一批通常有提取与独立查漏，遗漏续处理可能追加 |
| 连续事件理解 | 理解本轮事件、感受和挂念，仅符合权限的主要使用者私聊 | 每条合格消息最多新增一次事件理解；成功时复用情绪判断 |
| 自我参考与六维成长 | 从真实反馈整理可修正的自我认识；需要连续事件理解 | 至少积累12条合格原话，整理间隔至少6小时，每批另有一次整理调用 |
| 回应习惯学习 | 试验功能；学习明确的回应方式反馈，需要连续事件理解 | 复用事件理解，增加输入输出，不另发独立请求 |
| 空闲联想 | 试验功能；有真实记忆时延伸临时念头 | 一次生成最多三步；无来源不调用生成模型 |
| 联想感受 | 试验功能；有期限的轻微主观感受，需要空闲联想 | 复用联想输出，不单独调用 |

费用由模型、原话长度和实际批次决定，不是固定金额。查看可塑性记忆“花费”的分项记录；以模型服务账单为准。向导保留已有的额度、思考强度和其他高级参数。

### 初始性格

仅在确认没有既有性格来源、自我参考或积累原话时，才提供初始倾向选择。“均衡”“温暖”“轻快”是可调整的起点，也可逐项拖动六维。选择起点需要开启自我成长。

已有用户直接显示“保留已有性格与经历”。向导不覆盖你的旧性格、记忆、原话、关系、自然表达规则或白名单。需要改性格时请使用成长页面的明确修正入口。无法可靠确认是否全新的旧安装，也按已有用户处理。

名字和称呼可以在后续聊天中说明。起点不包含作者的人设、虚构背景、共同经历或私密聊天。短期心情与长期性格是不同的状态，不会为了让新用户看到变化就随机涨跌。

## 第三步：核对与保存

核对页显示“当前运行 → 本次保存”的开关变化和初始倾向。点击“保存这些选择”后，配置在下次重启心迹后生效。保存本身不会重启或打断聊天；请用心迹启动器“重启桥接”，或在运维页操作。没有守护进程的环境，退出后需要手动重新启动。

配置保存失败时不会显示成功。其他页面改过配置时，过期的向导会拒绝覆盖，请重新打开向导核对。已存在的经历文件不会跟着保存配置被改写；初始倾向也不能在以后重新打开向导时重置已有成长。

## 怎么判断成长是否在工作

总览展示最近一次检查结果，打开向导或点击页面刷新可重新检查。它不是实时计数器。

| 提示 | 含义 |
| --- | --- |
| 自我成长尚未开启 | 没有开启自我参考；不代表聊天或记忆系统也关闭 |
| 等待开启连续事件理解 | 上游事件理解未开启，原话尚不能按这条链路进入成长 |
| 等待配置私聊权限 | 主要使用者或当前模式权限不满足条件 |
| 尚无待整理经历 | 还没有待处理的合格原话，不会强行生成身份 |
| 正在积累 X/12 条 | 已积累原话，尚未达到自动整理批量 |
| 等待六小时整理间隔 | 原话足够，但尚未到下一次整理时间 |
| 已进入整理队列 | 等待后台调度，不代表已形成新认识 |
| 上次整理未完成 | 整理失败，原话仍保留；检查连接与模型，等待重试 |
| 有配置等待重启 | 已保存的选项与当前运行不同，重启后再检查 |

12条指通过校验、去重并进入成长队列的原话，不等于每发送12条消息必然改变人格。模型也可以判断“没有需要更新的认识”。长期六维变化需要至少三个日期的独立经历支持，并受七天变化间隔与变化边界限制；单次开心、争执或重复同一件事不会立刻改掉性格。

重启后在允许的 QQ 私聊正常聊一句，再检查真实收发、记忆处理和心绪记录。页面显示在线不证明回复已采用某条记忆。没有新增长期事实可能是正常筛选，应先查看原话和处理记录，而不是降低确认门槛。
