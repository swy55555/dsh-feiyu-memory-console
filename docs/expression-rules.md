# 自定义表达规则

入口：心迹桥接管理页 → 人格与指令 → 表达规则。

二代仿真的群聊、主人私聊、其他私聊、引用回复及跨聊天转达共用设置。此功能检查文本发送，不检查普通语音和唱歌内容，也不用于一代仿真。

## 如何设置

- **禁止发送的完整短语**：默认包括“这条我认”“这话我不接”“这份心意我收下了”。每行一条，可自行添加、删除；删除后保存即可取消。
- **只提醒的短语**：命中会记录提醒，仍正常发送。含义宽泛的词句建议放这里，避免误拦正常讨论。
- 每类最多 40 条，每条 3–60 字，不支持正则表达式。同一短语不能同时属于两类。
- 保存后对后续发送批次生效，也会保存到本地，重启仍保留。多个页面同时修改时，旧页面必须重新加载，避免覆盖新设置。
- 关闭“启用表达规则”可停用整个检查。内置的对仗和总结句式提示仅作提醒。

## 命中后发生什么

检查在发送前执行；分条回复作为整批检查，命中时不会先发出前几条。第一次命中把原因交回原聊天模型，允许一次完整改写。再次命中则停止发起调用的会话本轮工作，这批文字不发送；管理页留下记录。新的聊天输入到来后可以继续。转达失败不会停止接收方的会话。

不会偷偷删词或替换成固定安慰句。第二次失败后可能没有这一轮的文字回复，应在“最近检查记录”查看是否规则过宽。本轮停止后也不能换其他发送工具绕过检查。

本地匹配不调用模型；提示说明占用少量输入 token，退回改写仍会产生原聊天模型的费用。此功能不新增模型审核调用。

## 能力边界

带“原话、句式、刚才说”等讨论说明的成对引用，以及完整代码片段，可以豁免。单纯把整句加引号不能自动豁免。这里使用语法和文字匹配，并不可靠理解所有语境，也不能据此判断角色是否理解用户。

记录只保留命中短语、聊天标识、时间和处理结果，不保存完整草稿。设置由管理接口保护，聊天模型不能修改规则。

## 本次验证

55 组回归检查通过，其中新增 8 项表达规则测试，覆盖真实 HTTP 路由、群聊和不同私聊的独立重试计数、整批发送、引用例外、配置校验、重启保留、权限及新消息恢复。测试使用模拟发送，没有发出真实 QQ 消息或调用模型。

同时修复发送前私聊检查与当前回应参考访问认证辅助函数的作用域问题，沿用原权限判断，并通过真实 HTTP 处理链验证。
