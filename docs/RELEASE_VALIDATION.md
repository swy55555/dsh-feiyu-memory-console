## 必须保留的适用范围

源代码目录单独运行 `npm run check:engine` 会报告缺少 14 个 QQ 接入基础模块。它们来自已安装的兼容 QQ 桥接环境，本包不是完整 QQ 适配器分发包。升级夹具补齐相应基础模块后运行时结构检查通过；工程安装条件见 [INSTALL](../INSTALL.md)。

本轮没有完成真实账号端到端发送、长时间在线稳定性、所有宿主版本兼容性或独立人工标注的语义准确率评估。外部服务计价、网络可用性及模型判断仍可能变化。多文件 JSON 更新不是跨文件事务，费用估算不是供应商消费上限。

本版删除了当前源树和附件中的旧评估快照及不必要的旧文档，并将评估脚本输出移至用户数据目录。旧 Git 提交和旧 Release 附件不会随新版本发布自动消失，本记录不代表历史数据已清除。
