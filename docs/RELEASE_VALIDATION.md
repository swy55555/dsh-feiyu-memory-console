## 新增机制与局限

原话混合检索、有限补查、来源撤回与相邻问答整组交付有定向测试。拾光回忆测试覆盖原问题、多种问法、来源失效、两天时间范围、主人私聊隔离和 QQ 工具持续会话。真实安装中的拾光记录曾用于只读回放，能得到明确浏览参考和简短近期线索；这不构成模型回答正确率测试。

本轮未发送真实 QQ 测试消息，未恢复付费 LoCoMo 作答/裁判，也未重新计算人工标注通过率。没有测试所有 DSH 版本、首次 Python 模型下载或长期在线稳定性。记忆存在不保证每次检索命中或被模型正确使用；兴趣证据不证明主观喜欢。后台模型调用费用受服务商实际计费影响，内部预算不是消费硬上限。
