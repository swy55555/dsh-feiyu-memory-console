# 0.11.3 证据检索的部署与回退

本文件说明从 0.11.2 升级到 0.11.3 时的来源索引、配套代码、备份与回退。安装包本身不会自动迁移或切换正在运行的服务。开发基线为 `142e99e99ae55135e20d9596072975c7d11ef94a`；发布版本以 Release 标签与校验清单为准。

## 包和数据兼容性

采用同一候选包更新控制台、桥接与 memvec。新 Python 服务依赖同目录的 **server.py、evidence_store.py 和 lexical_rank.py**；只替换 server.py 会启动失败。桥接安装器已包含 retrieval-session.mjs、evidence-consumer.mjs、evidence-contract.mjs 及修改的既有模块。保留生产 config、state、.env、MCP/账号凭据、数据库、模型缓存与数据根目录；不要复制实验状态覆盖真实状态，不要重建 Profile，不要回退 DSH。

SQLite 增加 `evidence_index_meta`（版本 2）、FTS5 全文索引、来源向量、模型元数据、无正文通知表和 SQL 触发器。它们复用已有来源，不改写原业务记录。旧业务表无需格式转换。模块状态新增兼容 cursor 与来源标记。需要部署与重启 DSH 插件、QQ 桥接和 memvec 才能完整加载，不能凭文件哈希声称进程已加载。

## 只在新目录中演练

已有 Python 环境需能运行 numpy/fastembed；没有依赖时停止并报告，不让本脚本自动安装。把变量替换成已经核对的真实路径：

```powershell
$pythonExe = '已有 Python 可执行文件路径'
$sourceDatabase = '现有 memories.db 的绝对路径'
$newStage = '数据目录以外、尚不存在的演练目录'
& $pythonExe -B bin/migrate-evidence.py --source $sourceDatabase --stage $newStage
# 有完整本地模型缓存时才增加 --vectors；脚本强制模型离线。
# --reuse-vectors 可读入同来源版本、同模型的先前隔离索引，避免重复计算。
node scripts/prepare-evidence-release.mjs --out '源码树以外的新交付目录'
```

迁移工具以 SQLite backup 读取源库，生成 rollback.db、candidate.db、rollback-rehearsal.db 和报告。逐表比较原业务数据、重复重建、提交前回滚、SQL 中断后的恢复、完整性检查都必须通过。含真实数据的演练目录属于私密资料，不进入 npm 包或公开仓库。旧演练目录存在时拒绝覆盖。

## 现有安装的切换顺序

1. 核对部署清单每个文件的 SHA-256，记录生产当前代码和数据真实路径、启动命令、版本、开关与进程；确认基线后没有未合并热修复。
2. 暂停桥接发送和调度，再停止相关写进程；等待正在进行的写入结束。**此时再做一份最新 SQLite backup**，以及配置和桥接 state 的完整备份。开发阶段副本不能替代切换时备份。
3. 对这份最终快照重新运行上述迁移命令，确认原业务表哈希和来源计数。保留回退库。不要拿数小时前的演练库覆盖仍在写入的生产库。
4. 使用现有安装/升级入口安装候选包和桥接运行时；对 memvec 一次更新三个源码文件。只更新清单中的代码文件，不覆盖现有配置、凭据、状态或数据目录。若实际安装不支持整包升级，按部署清单人工复制代码文件，并逐项核对哈希。
5. 保持生产原数据路径启动 memvec，让可重建索引在原库内升级；也可在确认停写后的最终快照上完成迁移后替换，二者只能选定一种。启动桥接和 DSH，先保持主动行为关闭或原暂停状态。
6. 核验 `/stats`、数据库 integrity_check、索引版本/计数、会话权限和来源状态。用隔离会话核验精确原话、撤回/恢复、空结果、工具 ref、预算及旧回合失效；不要用真实 QQ 群发做验收。确认原有开关与数据根目录未改变，最后才按用户原选择恢复行为。

具体路径与逐文件哈希由交付目录的 `deployment-manifest.json` 和私有部署清单给出；重启入口因本机启动方式而异，不应在通用脚本中猜测进程名称并强杀。

## 回退条件和步骤

服务无法启动、来源/作用域异常、通知消费持续失败、原话计数不符或重要旧功能回归时，保留现场日志并暂停发送。停止相关写进程后，恢复同一份切换备份中的旧代码、配置和模块状态，再恢复其配套 SQLite backup；启动旧服务做只读完整性及权限检查。不得仅回退桥接而遗漏 memvec 配套文件。

若切换后已经有新聊天或管理写入，直接恢复切换前数据库会丢掉新写入：先留存故障现场快照，离线评估差异和补录，不能自动用旧库覆盖。回退不是降级 DSH 或把 E 盘数据搬回 C 盘。

检索、嵌入、迁移本身不使用收费生成模型；旧候选审核、摘要和聊天继续遵守原开关。安装或升级不会恢复已停止的 LoCoMo 作答/裁判任务。
