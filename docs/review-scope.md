# 可选的相关范围审核

v0.10.1 包含当前运行版中的范围选择能力。默认 `all`，即同聊天、同主体的全部有效旧事实；主动开启 `related` 后，只选择显式关联、相同事实键或同对象同属性的所有记录，另加最多六条语义相似记录作为补充。相同方面的记录不会截断为六条，仍可能需要多页模型审核。

这是一项费用与漏检风险之间的选择，不是已经验证等价于全量审核的优化。不同表述、跨属性约束、否定或结构提取错误可能使真实冲突落在范围之外。合成测试曾出现真实冲突只排在语义第20位的反例，因此默认不启用。没有证据支持固定节省比例或“不会漏冲突”的保证。

需要自行选择时，在实际记忆服务环境设 `MEMVEC_REVIEW_SCOPE=related`，或在服务数据目录的 `review-scope.txt` 写入 `related`。环境变量优先；恢复 `all` 可回到全量范围。发布包不包含这个本机配置文件。控制台「整理 → 服务状态」和服务 `/stats` 显示当前范围；范围内审核通过不代表全部历史已经审过。

原话支持、人物归属、否定与语气、有效期、版本和最终事务检查仍保留。切换模式不会批量确认旧候选，也不会打开自动审核。原话不支持的内容不会因为缩小关系范围而通过。已有已确认内容不会在切回全量时自动回滚或重新审查，仍需按需检查。

审核回执仅证明其覆盖的候选与事实组合；全量范围有额外事实时仍需补审。不要把相关范围模式称为免人工的自动经历分流，后者尚未实现。
