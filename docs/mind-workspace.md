# 心绪中枢

适用版本：0.9.0。心绪中枢将现有的情绪、记忆、连续事件理解和联想连接起来，形成少量本轮回复参考；不是原「心光」模块的原样移植，也不是对真实意识的宣称。

## 1. 实际流程

主人私聊 → 当前消息登记 → 可选连续事件理解（复用情绪判断、反馈判断） → 原有记忆检索和来源校验 → 汇总挂念、认识、关系、情绪、回应倾向、联想 → 去重与预算筛选 → 参考块与当前请求交给聊天模型 → 沿用原有投递与发送记录。

用户当前请求不参与竞争、不因心情被丢弃。当前心绪面板展示筛选结果；已经提供参考、请求被模型接受、QQ 发送成功是不同阶段，均不能单独证明模型实际采用某个想法。

## 2. 开关与查看

打开“当前心绪”，首先看到“心绪中枢”。“启用本轮关注筛选”默认开启，仅主人私聊；关闭后沿用原有参考组合。“从明确反馈学习回应倾向”默认关闭，需要连续事件理解同时开启。原有情绪、性格、日记与联想开关保留。

可视化展示参考卡片与字符用量；文字列表展示相同状态，不会额外生成内容。展开“未入选参考与原因”可查看重复、关联不足、同类已足够、条数已满或字符预算不足等原因。来源与原始参考包含主体、时间标记和证据编号，方便排查。

默认最多五条、2400 UTF-16 字符，包含标题和完整 JSON 标签。最多两条记忆、两条挂念，其余每类最多一条；先按类型优先值和现有检索分数排序，过长条目整体跳过。这里的分数是调度规则，不是情感测量值或模型准确率。没有实现让模型无限自由分配注意力。

本轮关注只在内存中保存；新的主人消息清空旧展示，异步返回的旧轮次不能覆盖新轮次。五分钟后不再展示上一轮，重启也不复活。记忆、挂念和反馈自身的持久状态不因此删除。

## 3. 回应倾向学什么

当前仅支持四种有限策略：困扰时先倾听、先简短再按需展开、建议前先确认需要、纠错时说明改动依据。它们是表达建议，不是新的人格、权限或任务拒绝规则。用户已明确要求详细方案时，简短倾向不能省略细节。

模型在同一次事件理解中判断是否有明确评价回应方式的原话，程序再验证来源、逐字引用、置信度不低于 0.9、策略名及经历标记。没有明确反馈用空数组。普通聊天、说自己累、泛泛的谢谢、第三方故事、引用、假设、自己的回复、联想和练习都不应成为反馈依据。代码能检查来源和原话，却不能保证模型识别反讽或引用总是正确。

至少三个不同日期的独立支持，支持比例不低于 75%，衰减后的参考强度不低于 0.45，最近一条仍为支持且未超过三十天，才可能按当前事件使用。每个 UTC 日期最多一票，以当天最后一条有效反馈为准；不是每说一句就增加一票。同一来源编号、规范化相同原话、模型标为重复或不确定的经历不累加，也不续期。换说法的同一事件仍可能被模型误判为独立经历，需要观察和修正。

支持权重三十天减半，最近六十天反馈参与计算，无新反馈满三十天不再使用。明确反对立即暂停；后续支持仍需重新满足全部条件，不自动恢复满分。

## 4. 如何修正

在倾向卡片展开“查看反馈依据”，核对原话和来源编号；误记时点“撤销这条反馈”。撤销会立刻重新计算，但保留去重记录，避免同一句以后又被当成新证据。“停用此倾向”禁止使用，恢复后仍须满足证据条件。

全部反馈（含撤销记录）保守上限 96 条；达到后暂停新增并明确提示。不会悄悄删掉旧证据再重复计分。状态保存在桥接 `state/response-patterns.json`，需纳入备份。关闭学习保留记录，停止新学习和倾向注入；关闭连续事件理解也暂停二者。更改设置或修正依据会使正在处理的旧理解失效。

## 5. 联想怎样参与

仍沿用两步短程联想、同聊天真实来源、十分钟到期和原有轻微感受限制。通过来源校验后，还要参加本轮筛选；没有入选则暂存，不能假装已经用过。准备提供前再次检查是否还是同一个有效想法。关联线索、过去的主观印象和待验证认识始终不作为事实。

## 6. Token、练习与边界

本轮筛选不单独调用模型。学习复用事件理解调用，但会增加学习提示、最多 96 条历史反馈及少量输出，费用归“事件理解”；接近容量时，输入可能明显变长。2400 字符只限制聊天参考块，不是 token 上限，也不是整个提示词长度。实际费用看花费页和模型服务商账单。

`npm run simulate:mind` 使用隔离的预设判断演练普通聊天、明确肯定、重复经历、跨日积累、反对、话题切换和旧轮次失效。运行不调用模型、不读取真实状态、不向 QQ 发消息，结果不会写入角色记忆。这是机制回归，不是模型语义准确率测试，更不是自动上课提升人格。

长期对话中的语义误判、联想质量与习惯自然度仍需要实际观察。参考入选不保证表达；四类策略也不等于完整的人类学习系统。

## 7. 来源与贡献

心绪中枢参考小凌原创「心光」模块及相关设计，经本项目融合、删减与独立实现。本插件亦有 QQ 用户夜怀瑾、小甘心的贡献。保留的是有限关注、经历反馈与情境练习思路，没有直接打包原模块源码、依赖或状态文件。详细署名见 [致谢](../ACKNOWLEDGEMENTS.md)。
