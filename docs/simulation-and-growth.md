# 二代预设、自我发展与旧角色设定

适用版本：0.10.1，未发布。

## 各自负责什么

二代预设负责权限、消息读取、工具调用、发送与等待协议，也保留完整的自然表达要求。自我参考与六维记录可修正的身份理解、兴趣和相处倾向。本轮对话决定具体回应、长度和态度；文风样例帮助措辞，不规定人物关系或强制性格。

当前明确的表达反馈优先于旧偏好及文风样例，但不改变权限和工具边界。自我发展不是重训底层模型，也不会产生新的管理权限；它通过有来源的记忆和可修正参考影响后续生成。

## 这次处理了哪些冲突

| 原要求 | 调整后 |
| --- | --- |
| 照文风包的语气、开头、句长说；文风包压过人设 | 文风包仅作措辞参考，不覆盖当前明确偏好、六维或自我参考 |
| 群友式短句、选择性接话、模仿群友 | 明确限定在当前群聊；私聊和认真交流按具体需要回应 |
| 想说两句就分为两个数组元素 | 连贯表达可以放在一条中，确有独立补充才分条 |
| 用“刚没看手机”“去忙了”解释离场 | 只说明可确认的情况，不虚构线下生活 |
| 用不接话、不感兴趣突出主体性 | 允许不同意、拒绝，也允许赞同与关心；不用冷淡或挑刺证明独立 |
| 记忆参考要求“沿用既有人设” | 采用当前自我参考和明确表达要求，不恢复已停用脚本 |

完整“自然表达与防 AI 味”段落保持不变。权限、安全、工具与等待协议保持原文；没有减少文风检查边界，也没有新增模型调用。迁移只替换已知旧规则，不按关键词批量删除自定义内容。安装可使用 `--preset qq-chat-v2` 单独更新二代，一代和后台整理预设不变。

## 为什么停用角色卡后还会提到旧来历

停用卡片只阻止后续注入，无法删除已经进入旧会话的工具返回和模型上下文。历史里的自述、摘要也可能让模型沿用旧说法。

本机排查发现，“2023 年生于杭州一间机房”确实来自旧角色卡，历史会话的工具返回曾带入完整卡片。检查时，当前自我参考、当前新会话以及记忆服务的长期记录和摘要中没有查到这条来历。因此确认存在旧设定来源，但没有把用户所指的具体复述轮次完整还原出来，也不声称所有残留已清除。

处理方式是明确来源与用途：旧卡、旧工具结果和摘要中的来历只能证明过去使用过该设定；没有独立依据时，不作为当前事实，也不另编身世。历史可以回顾，真实交流经历保留。摘要生成也需保留“当时说法／设定”的性质，不能把角色自述升级为已证实事实。本次没有删除真实消息，没有按“杭州”等词过滤用户的生活信息，没有重置六维或成长记录。

## 生效与验证

二代预设源文件通过受支持的 YAML 处理器更新，再生成 DSH 的 bundle 产物；生成失败回滚。修改预设需要重启 DSH，修改动态参考需要重启桥接。旧会话的历史仍可能影响表达，因此文件一致、加载成功和实际聊天自然，是三个不同的验收结果。

在隔离安装副本中检查完整自然表达段、权限与工具协议、等待协议逐字保留；验证仅二代发生改变、非提示词配置不变、重复安装无变化。单元检查覆盖迁移边界、个体偏好、历史引用与参考隔离。未为本次改动新增付费模型评测，不把配置和回归通过当作自然聊天已经改善的证据。

本机验收：34 组回归检查及 DSH 预设产物契约检查通过，已安装并重启 DSH 与心迹，记忆服务保持运行。页面和只读接口确认新版预设文件一致、动态自我参考包含来源边界、服务连接正常；配置未变，原有十条自我参考内容与六维数值保留。后台状态文件在工作期间有正常更新，没有用旧备份覆盖它们。尚未对安装后的真实回复作效果验收，也未宣称每个旧会话历史都已清除。
