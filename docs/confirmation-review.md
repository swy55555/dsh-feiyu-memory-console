# 确认联合复核与结果复用

适用：0.10.0。

## 改了什么

自动确认一条候选之前，旧流程先检查它与已有事实的关系，再另起一次调用核对完整原话。两次都要读候选、规则和相近的背景。

现在第一次调用同时输出两份独立判定：完整原话能否支持候选，以及候选与当前历史页的关系。一页最多八条旧记忆，更多历史继续分页；后续页复用已保存的原话判定，只检查该页关系。不同主体、不同聊天的数据不混在一起。

原话支持不足、归属不明、引用、假设等仍保留待确认。已有事实有冲突、更正或不确定关系时，不自动覆盖。合并没有降低置信度阈值，也没有取消任何历史页。

没有旧记忆时只做一次原话审核；旧版本已完成所有关系页但没有原话回执时，只补一次原话审核，不重新付费检查已完成的历史页。手动确认仍代表用户主动确认事实，不强制复用自动确认的原话判断。

## 缓存如何避免重复花费

1. 记忆服务把原话回执保存在 `memory_evidence_reviews`，关系页继续使用 `memory_review_pages`。两份结果同时到达时在同一事务中校验、保存，任何一份不完整就整批拒绝。
2. 完整历史集合版本用于分页提交和最终确认；原话与两两关系回执还绑定具体内容指纹。候选、原话、来源、主体或相应旧事实改变时对应回执失效；新增无关事实不会让全部未变化的关系重新审核。普通读取次数变化不使缓存失效。详见下方依赖复用说明。
3. 桥接额外提供进程内的并发去重和短期重试缓存。相同请求同时到来只调用一次模型，成功且通过格式校验的结果最多保留 128 项、30 分钟；读取不续期。请求种类、原话、上下文、分页、版本、操作、模型或推理档位变化均使用新键。失败结果不缓存。
4. 自动确认事务再次检查数据库当前版本、所有历史页是否完成、原话回执是否达标及候选是否过期。缓存不是绕过确认条件的通行证。

进程内缓存会在重启后清空，数据库回执在重启后保留。缓存命中不触发模型请求，也不新增 token 费用；既有调用账本不会被删除或改写。

原话本身不支持的候选，在候选或原话未变化时不会因为新增另一条记忆反复调用。历史冲突类候选则会在其审核上下文变化后允许重新检查。

## 哪些仍然独立

- 记忆提取与提取查漏继续分开，避免恢复成“提取模型自己宣称完成”。
- 空闲联想继续按空闲触发，不加入每条消息的即时理解请求。
- 事件理解已有的情绪结果复用继续保留。
- 群聊与其他私聊的记忆共享范围没有扩大，自动确认仍限定允许的主人私聊。

花费页新增“确认联合复核”，默认 `high`，可以独立调节档位。“事实复核”继续用于后续分页和手动操作；“候选核对”保留旧入口兼容。历史账本中的旧分项保持原来归属。

## 实测与边界

2026-10-30，使用 `deepseek-account / deepseek-flash / high`，对四组合成情景分别运行旧的两个审核请求和新的联合请求。案例包括不同食物共存、引用不算本人偏好、明确更正、适用条件不同。两种流程的原话与关系检查均通过。

| 本次样例合计 | 原独立流程 | 联合流程 |
|---|---:|---:|
| 模型调用 | 8 | 4 |
| 输入 token（含缓存命中） | 10,892 | 6,508 |
| 输出 token | 900 | 976 |
| 总 token | 11,792 | 7,484 |

样例内总 token 减少约 36.5%，主要来自重复输入减少，输出没有减少。这里只比较候选确认步骤，不代表全部心绪和记忆开销会下降相同比例。缓存命中的输入与输出价格不同，token 降幅也不等于金额降幅；长期表现需要更多真实聊天观察。

验证还覆盖：并发只调用一次、缓存失效、返回对象不污染缓存、失败重试、分页完整性、停止自动核对、来源与版本变更、跨聊天隔离、负面回执不自动确认，以及无完整原话回执时不能直接自动确认。

部署需要同时更新控制台宿主、桥接运行时与记忆服务。旧版回执不会被冒充为新的原话回执；缺少新能力时自动确认会停止并等待同步升级。本版运行时管理文件以安装器检查结果为准（已知 QQ MCP 可额外迁移），原话回执表为增量建表，不删除已有记忆与原始账本。

## 避免历史集合变化引起全量重审

本版保存两种独立的内容回执：候选完整原话核对、候选与每条旧记忆的关系核对。复用时同时核对作用域、操作、候选完整指纹和旧记忆完整指纹；文本、来源、主体、状态等改变即失效，读取次数变化不失效。历史集合新增无关条目时，未变化的旧关系不必从头审核。

分页仍最多八条；仅当该页所有关系都有匹配回执才能跳过，含新增或变化关系的页面仅补审缺失关系。完整原话核对可独立复用。最终确认仍以当前历史集合版本为准，新事实未审核、负面原话结论、作用域不匹配或并发变化均不能绕过。

旧版回执无法证明独立依赖的，不猜测迁移，保守重审一次后建立新回执。缓存只减少相同内容的重复工作，不把模型结论升级为永远正确，也不删除查漏与冲突复核。


## 可选审核范围

本版保留默认全量审核，也提供显式开启的相关范围模式：审核选入的同方面事实和少量语义近邻，可能漏掉范围外冲突。页面显示的“审核通过”仅指当前选定范围；原话、有效期和版本检查仍保留。详见[配置与限制](review-scope.md)。此模式不等于所有候选自动生效。
