# 心迹插件 · 信息架构与视觉重设计（提案 v1）

> 2026-11-02 · 先定结构，再改代码。
> 目标：模块名各有所指、记忆类合并、视觉从“后台工具”变成“安静的桌面”。

---

## 1. 现在的问题

1. **命名太窄**：「心象」「年轮」都只能覆盖一部分（记忆 / 性格 / 情绪 / 成长 / 证据）。
2. **记忆类碎片化**：记忆图、长期记忆、轻量记忆、日记、整理、会话上下文，本质都是“她记得什么”，却分散成 5~6 个 tab。
3. **情绪和性格混在一起**：一个是快变量，一个是慢变量，应该分开。
4. **工具类和内容类混排**：玩梗、花费和记忆并列，视觉权重一样。
5. **视觉**：卡片多、边框多、层级平，像运维面板，不像她自己的空间。

---

## 2. 命名系统

### 主名：**回响**

> 记忆是过去留下的声音，情绪是当下的共振，性格是声音的底色——最后都在回复里回响。

比「心象」宽：不偏向“看”，也不偏向“记忆”，能盖住整套。

### 模块名（每个都有实际所指，不是装饰）

| 分区 | 名字 | 覆盖什么 | 为什么 |
|---|---|---|---|
| 记忆 | **回廊** | 记忆图 / 长期 / 短期 / 日记 / 整理 / 会话上下文 | 走回去看的地方；这些都只是“怎么翻” |
| 性格 | **轮廓** | 六维、自我参考、人格依据 | 性格是形状，不是情绪 |
| 情绪 | **潮汐** | 情绪、心情、关系张力 | 有涨落、会退 |
| 成长 | **年轮** | 成长课堂、课程、作业本 | 一圈一圈长 |
| 证据 | **拾光** | 证据脉络（目标/挂念/兴趣/自我记忆/运行状态） | 自己捡回来的光 |
| 玩梗 | **梗库** | 表情、梗、lore | 工具，不必诗意 |
| 花费 | **账本** | token、费用 | 工具，不必诗意 |

导航分组：

```
她
  轮廓   性格
  潮汐   情绪
  年轮   成长课堂

记忆
  回廊   记忆图 / 长期 / 短期 / 日记 / 整理 / 会话上下文

运行
  拾光   证据脉络

工具
  梗库
  账本
```

## 3. 记忆合并方案（重点）

现在 6 个入口合成 **1 个「回廊」**，内部用二级视图：

```
回廊
 ├ 时间线     长期记忆按时间排（默认）
 ├ 图谱       关系图
 ├ 短期/轻量  临时便签
 ├ 日记       公开 / 私密
 ├ 整理队列   待确认、待整理
 └ 上下文     会话摘要 + 原文片段
```

理由：

- 它们回答的是同一个问题：「她记得什么、从哪来、可不可信」；
- 合并后可以统一做搜索、筛选、来源展开；
- 会话上下文不再单独藏一个入口，它就是记忆的一种。

## 4. 视觉方向

### 4.1 现在的毛病

- 每个卡片都描边 + 半透明，边界比内容还抢眼；
- 标题和正文同色同重，扫读困难；
- 强调色到处都是，青色失去了“可点/当前”的含义；
- 间距偏小，信息挤在一起。

### 4.2 新的规则

| 项 | 规则 |
|---|---|
| 底色 | 深色 `#0b161a`，面板 `#10232a`（实色，不用半透明） |
| 描边 | 只在分区之间用 1px `rgba(150,205,220,.10)`，卡片本身不描边 |
| 强调色 | 青蓝 `#7fd6e6` 只用于：当前 tab、可点链接、关键数字 |
| 标题 | 衬线体（Songti）20/16px；正文 sans 14px；辅助 12px `#7f99a5` |
| 间距 | 页面 28px，卡片 20px，行 10px |
| 圆角 | 12px（卡片）/ 999px（标签） |
| 阴影 | 默认无；只给浮层和 hover |
| 图表 | 2px 细条，轨道 `rgba(150,205,220,.08)` |

### 4.3 页面骨架

```
┌ 侧栏 200px ─┬─ 主区 ─────────────────────────────┐
│ 她          │ 页面标题（衬线）+ 一句说明          │
│  轮廓       │ ┌ 主内容 2fr ─┐ ┌ 说明/状态 1fr ┐ │
│  潮汐       │ │             │ │               │ │
│  年轮       │ │             │ │               │ │
│ 记忆        │ └─────────────┘ └───────────────┘ │
│  回廊       │                                    │
│ 运行        │                                    │
│  拾光       │                                    │
│ 工具        │                                    │
│  梗库 账本  │                                    │
└─────────────┴────────────────────────────────────┘
```

- 侧栏只放导航，不放大段说明；
- 每个页面统一「标题 + 一句说明 + 主内容 + 右侧状态」；
- 右侧状态栏放“数据来源/更新时间/只读/失败原因”，不重复主内容。

### 4.4 拾光页（证据脉络）的调整

- 去掉三栏等宽；改成 **主栏（证据）+ 窄栏（运行判断）**，挂念和状态参数收到主栏顶部横向条；
- 每条证据的“来源”收成一行小字 + 展开，不默认占一大块；
- 置信度、暂定/确认用标签，不用颜色块；
- 顶栏状态只保留：桥接 / memvec / 只读 / 刷新时间。

---

## 5. 实施顺序（建议）

1. **改名 + 导航重排**（只改显示名和 tab 结构，不动数据）；
2. **记忆合并**（回廊二级视图，复用现有五个视图的渲染函数）；
3. **视觉 token 替换**（底色/描边/字重/间距）；
4. **拾光页重排**（去掉三栏等宽）。

每一步都可以单独验收，不用一次全改。
